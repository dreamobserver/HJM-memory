## Codex

对，你看到的是正常的：**Codex 本身一般不能像 Cherry Studio / Clash Verge 那样通过“CSS 注入”直接改外观**。

原因大概是这几个：

1. **Codex 没有开放自定义 CSS 入口**  
   Cherry Studio 有 `自定义 CSS` 设置，Clash Verge 有 `CSS 注入`。Codex 桌面端目前没有类似的官方入口。

2. **Codex UI 是受控应用界面**  
   它不像网页插件那样允许用户随便插入样式。这样做主要是为了稳定性、安全性和避免界面功能被 CSS 改坏。

3. **即使本地有前端资源，也不建议强改**  
   有些 Electron 应用理论上能改安装目录里的样式或注入脚本，但更新后会失效，也可能破坏签名、缓存或导致启动异常。Codex 这类开发工具更不适合这么折腾。

所以结论是：**Cherry Studio、Clash Verge 可以靠 CSS 注入换皮；Codex 目前不适合，也没有正常的 CSS 注入通道。**

如果你只是想让 Codex 看起来更舒服，比较现实的是调系统深浅色、缩放、字体渲染，或者等官方以后开放主题/自定义外观。
