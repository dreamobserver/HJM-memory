# 用户：

什么是嘉立创返单

# DeepSeek：

**原始回答**

**嘉立创返单**是指在嘉立创平台基于历史订单快速重新下单的功能，适用于PCB打样、小批量生产等场景。以下是其主要特点和使用方式：

### 1. **返单的定义**
返单（拼音：fǎndān）是指对上次订货的重新订购，用户可以直接基于历史订单信息快速生成新订单，无需重复填写所有参数。

### 2. **嘉立创返单的适用场景**
嘉立创的返单功能支持多种修改情况，包括：
- **修改拼版方式**：如上次是单片生产，本次可改为拼版生产。
- **调整阻焊颜色**：如从绿色改为蓝色。
- **更改板厚**：如从1.6mm改为1.2mm。
- **变更焊盘喷镀工艺**：如从无铅喷锡改为有铅喷锡。

### 3. **返单的优势**
- **快速下单**：减少重复填写信息的时间，提高效率。
- **避免错误**：返单会带入源单的工艺信息，并在提交时提示关键参数，降低出错概率。
- **支持多种调整**：即使文件有修改（如拼版调整），仍可使用返单功能。

### 4. **如何进行返单操作**
1. 在嘉立创下单助手中选择历史订单，点击“返单”。
2. 修改需要调整的参数（如板厚、阻焊颜色等）。
3. 提交订单，系统会提示关键工艺变更，确认无误后完成支付。

### 5. **注意事项**
- 部分特殊情况（如样板未发货就返单生产）需额外注意系统提示。
- 返单功能适用于文件未做大幅修改的情况，若设计有重大调整，可能需要重新审核。

嘉立创的返单功能极大提升了重复订单的下单效率，特别适合需要微调参数或批量生产的用户。如需更详细的操作指南，可参考嘉立创官网或下单助手帮助文档。

# 用户：

在软件哪一层设计插件孔(Pad )，孔属性和参数会在打孔图（分孔图）中显示？

# DeepSeek：

**原始回答**

在PCB设计软件中，**插件孔（Pad）**的设计和显示涉及多个图层，具体如下：  

### 1. **插件孔（Pad）的设计层**  
插件孔通常设计在 **Multi-Layer（多层）** 或 **Top/Bottom Layer（顶层/底层）**，具体取决于软件：  
- **Altium Designer / Protel**：  
  - 插件孔（PTH孔）一般放在 **Multi-Layer**，因为它贯穿所有层。  
  - 如果是单面板的插件孔，可以仅放在 **Bottom Layer**（底层）。  
- **PADS / KiCad**：  
  - 插件孔通常定义为 **Drill层** 或 **Pad Stack**，并关联到 **Top/Bottom Layer**。  

### 2. **孔属性在分孔图（Drill Drawing）中的显示**  
分孔图（Drill Drawing）主要用于标注钻孔位置、孔径、类型（金属化/非金属化）等信息。要使其正确显示插件孔，需注意：  
- **Altium Designer**：  
  - 在 **Drill Drawing层** 放置 **.Legend** 字符串（带英文句点），系统会自动生成分孔图表格。  
  - 孔属性（如孔径、金属化/非金属化）会显示在分孔图表格中。  
- **PADS**：  
  - 分孔图信息通常由 **Drill Drawing层** 或 **NC Drill文件** 提供。  
  - 槽孔等特殊孔需在 **Drill Drawing层** 额外标注。  

### 3. **关键参数设置**  
- **金属化孔（PTH）** 和 **非金属化孔（NPTH）** 需明确区分：  
  - PTH孔（如插件孔）需在 **Pad属性** 中勾选 **Plated（镀铜）**。  
  - NPTH孔（如螺丝孔）需设置为 **Non-Plated**，并在分孔图中标注。  
- **孔径和焊环**：  
  - 插件孔（PTH）焊盘外环单边建议 ≥ 0.2mm（8mil），避免生产偏孔。  

### 4. **Gerber输出时的注意事项**  
- **必须包含 Drill Drawing层**（分孔图）和 **NC Drill文件**（钻孔数据），否则可能导致漏孔或孔属性错误。  
- 在 **Altium Designer** 导出Gerber时，需勾选 **Drill Drawing Plots** 并设置 **符号标注方式**（如字符或图形）。  

### **总结**  
| **项目** | **设计层** | **分孔图显示方式** |  
|----------|------------|------------------|  
| **插件孔（PTH）** | Multi-Layer / Top/Bottom Layer | Drill Drawing层 + NC Drill文件 |  
| **非金属化孔（NPTH）** | Mechanical Layer / Drill Drawing层 | 需额外标注 |  
| **槽孔** | Drill Drawing层 / 机械层 | 需在分孔图标注 |  

正确设置这些参数可确保PCB生产时孔位、孔径和属性无误，避免因文件不完整导致加工错误。
