### 方法 1：使用正则表达式替换（推荐）
1. 按 **Ctrl+H** 打开替换窗口
2. 在顶部切换为 **"正则表达式"** 模式（点击 `.` 图标或按 **Alt+E**）
3. 设置如下：
   - **查找内容**：`\b11121\b`
   - **替换为**：`新数值`（例如 `12345`）
   - 范围：确保选中整个文件
4. 点击 **"全部替换"** (Alt+A)

### 方法 2：列编辑模式（适合局部修改）
1. 将光标定位到第一个 `11121` 的开头
2. 按住 **Alt** + **鼠标左键** 向下拖动，选中所有需要修改的数值列（避开注释和逗号）
3. 直接输入新数值（如 `12345`），完成后按 **Enter**
