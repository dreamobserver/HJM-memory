### 三、工具分类：静态分析与动态分析

您使用的工具可以清晰地分为两大类，它们的目的和使用时机完全不同。

| 工具 | 分类 | 用途与区别 |
| :--- | :--- | :--- |
| **Ghidra** | **静态分析** | **目的：** 像看地图一样，在不运行程序的情况下分析代码结构。<br>**用途：** 反编译、查看算法逻辑、**字符串搜索、交叉引用分析**（这是您成功的关键）。<br>**比喻：** **“尸检”**——在程序静止时对其进行解剖。 |
| **CFF Explorer** | **静态分析** | **目的：** 查看PE文件结构（节表、导入表、资源等）。<br>**用途：** 快速查看程序信息、资源提取。 |
| **HxD** | **静态分析** | **目的：** 十六进制编辑，直接修改文件字节。<br>**用途：** 最终实施修补的工具。 |
| **Resource Hacker** | **静态分析** | **目的：** 专门用于查看、提取、修改Windows程序的资源（对话框、菜单、字符串表等）。 |
| **x64dbg** | **动态分析** | **目的：** 在程序运行时像操纵手术刀一样实时干预其行为。<br>**用途：** 下断点、单步执行、查看修改寄存器和内存值、分析调用堆栈。<br>**比喻：** **“外科手术”**——在程序活着的时候进行干预和观察。 |
| **PyCharm & Python COM工具** | **动态分析（环境干预）** | **目的：** 不属于程序分析工具，而是用于**控制和改变程序运行的环境**。<br>**用途：** 您编写它来模拟COM口被占用的情况，这是一种**测试用例的构造**，用于触发程序的特定行为（错误弹窗），从而辅助分析。 |

### 核心区别总结：

-   **静态分析**：**离线**的，针对**文件本身**。优点是全局视野、安全；缺点是可能无法看到运行时的真实数据。
-   **动态分析**：**在线**的，针对**运行中的进程**。优点是能获取实时状态、验证猜想；缺点是可能被反调试机制干扰，操作更复杂。
