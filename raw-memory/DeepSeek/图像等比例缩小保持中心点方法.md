# 用户：

如何将一张图等矢量缩小至1292*964，保持其中心点不变

# DeepSeek：

**原始回答**

要将一张图像或矢量图形等比例缩小至1292×964像素，并保持中心点不变，可以按照以下步骤操作（以常见工具为例）：

---

### **1. 使用Photoshop**
1. **打开图像**：文件 → 打开（Ctrl+O）。
2. **解锁背景层**：双击图层锁图标 → 点击“确定”。
3. **调整画布大小**（确保中心定位）：
   - **菜单**：图像 → 画布大小（Alt+Ctrl+C）。
   - 输入目标尺寸（1292×964），锚点选择**中心**（默认即为中间格子）。
   - 点击“确定”裁剪多余部分（如有需要）。
4. **等比例缩放图像**：
   - 按Ctrl+T（自由变换）→ 按住Shift键（保持比例）拖动角点。
   - 或通过 **图像 → 图像大小**（Ctrl+Alt+I）输入目标尺寸，勾选“约束比例”。

---

### **2. 使用Illustrator（矢量图形）**
1. **选择对象**：用选择工具（V）选中图形。
2. **等比例缩放**：
   - 按住Shift拖动角点，或双击“缩放工具”（↔）输入统一比例（如50%）。
3. **中心对齐画布**：
   - 打开“对齐面板”（Shift+F7）→ 选择“对齐画布” → 点击“水平居中对齐”和“垂直居中对齐”。

---

### **3. 使用GIMP（免费工具）**
1. **菜单**：图像 → 画布大小 → 设置1292×964，锚点选中心。
2. **缩放图像层**：工具 → 变换工具 → 缩放 → 按住Shift调整图层大小。

---

### **4. 注意事项**
- **等比例条件**：若原图比例与1292:964（约1.34）不同，强制缩放会导致变形。可先裁剪至相似比例再缩放。
- **矢量图形**：在AI或Inkscape中直接调整画布尺寸并居中对象，矢量无损缩放。

---

根据工具选择对应方法，核心步骤均为**“中心锚点定位”+“等比例缩放”**。

---

### **方法 1：使用 MATLAB（精确控制）**
```matlab
% 读取图像
img = imread('your_image.jpg'); % 替换为你的图片路径
[height, width, ~] = size(img);

% 目标尺寸
targetWidth = 1292;
targetHeight = 964;

% 计算缩放比例（保持长宽比）
scale = min([targetHeight/height, targetWidth/width]);
newSize = round([height, width] * scale);

% 等比例缩放图像
resizedImg = imresize(img, newSize);

% 创建空白画布（填充背景色，例如白色）
canvas = uint8(255 * ones(targetHeight, targetWidth, 3));

% 将缩放后的图像居中粘贴到画布
startRow = floor((targetHeight - newSize(1)) / 2) + 1;
startCol = floor((targetWidth - newSize(2)) / 2) + 1;
canvas(startRow:startRow+newSize(1)-1, startCol:startCol+newSize(2)-1, :) = resizedImg;

% 保存结果
imwrite(canvas, 'output_image.jpg');
disp('图像已保存为 output_image.jpg');
```
**说明**：  
- 代码会自动保持原图比例，缩放到能完全放入 `1292×964` 画布的最大尺寸，多余部分填充白色（可修改 `255` 为其他值调整背景色）。
- 若需强制拉伸至 `1292×964`（不保持比例），直接使用 `imresize(img, [964, 1292])`。
