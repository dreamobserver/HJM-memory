```python
from PIL import Image, ImageDraw
import numpy as np

def generate_grid_image(width=1024, height=768, grid_size=32, marker_size=4):
    """
    生成带定位标记的黑白方格图
    参数:
        width: 图像宽度(默认1024)
        height: 图像高度(默认768)
        grid_size: 每个方格的大小(默认32像素)
        marker_size: 定位标记的大小(默认4×4方格)
    """
    # 创建空白图像
    img = Image.new('1', (width, height), color=1)  # 1表示白色
    
    # 准备绘图对象
    draw = ImageDraw.Draw(img)
    
    # 绘制横向网格线
    for y in range(0, height, grid_size):
        draw.line([(0, y), (width, y)], fill=0)  # 0表示黑色
    
    # 绘制纵向网格线
    for x in range(0, width, grid_size):
        draw.line([(x, 0), (x, height)], fill=0)
    
    # 添加四个角落的定位标记(反色方块)
    marker_pixels = marker_size * grid_size
    
    # 左上角标记
    draw.rectangle([0, 0, marker_pixels, marker_pixels], fill=0)
    draw.rectangle([grid_size, grid_size, 
                   marker_pixels-grid_size, marker_pixels-grid_size], fill=1)
    
    # 右上角标记
    draw.rectangle([width-marker_pixels, 0, width, marker_pixels], fill=0)
    draw.rectangle([width-marker_pixels+grid_size, grid_size, 
                   width-grid_size, marker_pixels-grid_size], fill=1)
    
    # 左下角标记
    draw.rectangle([0, height-marker_pixels, marker_pixels, height], fill=0)
    draw.rectangle([grid_size, height-marker_pixels+grid_size, 
                   marker_pixels-grid_size, height-grid_size], fill=1)
    
    # 右下角标记
    draw.rectangle([width-marker_pixels, height-marker_pixels, width, height], fill=0)
    draw.rectangle([width-marker_pixels+grid_size, height-marker_pixels+grid_size, 
                   width-grid_size, height-grid_size], fill=1)
    
    # 中心标记(可选)
    center_x, center_y = width//2, height//2
    half_marker = marker_size//2 * grid_size
    draw.rectangle([center_x-half_marker, center_y-half_marker,
                   center_x+half_marker, center_y+half_marker], fill=0)
    
    return img

# 生成图像
grid_image = generate_grid_image()

# 保存图像(可根据需要选择格式)
grid_image.save('slm_grid_pattern.bmp')  # BMP格式保证无损
# grid_image.save('slm_grid_pattern.png')  # 或PNG格式

# 显示图像(可选)
grid_image.show()
```

### 方案特点：

1. **快速定位功能**：
   - 四个角落添加了特殊标记（中心标记可选）
   - 每个标记由4×4方格组成（大小可调）
   - 采用"回字形"设计，便于视觉识别

2. **坐标系统**：
   - 图像坐标系原点(0,0)在左上角
   - 每个方格尺寸默认为32×32像素（可通过参数调整）
   - 总网格尺寸：横向32格(1024/32)，纵向24格(768/32)

3. **输出格式**：
   - 使用黑白二值图像（1位深度）
   - 推荐BMP格式保证无损，适合SLM输入

4. **扩展性**：
   - 可调整网格大小适应不同分辨率需求
   - 可修改标记样式或添加编号

### 如何定位：
1. 通过四个角落标记确定图像边界
2. 中心标记辅助定位（可选）
3. 网格坐标计算：(x坐标//32, y坐标//32)得到网格位置

如需更复杂的坐标标记（如行列编号），可以进一步扩展此代码。

**原始回答**

要计算CCD相机的分辨率需求，使得**中间黑色大方格占据CCD视场的55%-65%**，我们可以按照以下步骤进行分析和计算。这里假设您已经知道：

1. **中间黑色大方格的物理尺寸**（例如，通过SLM像素尺寸和方格像素数计算得出）
2. **CCD的像素尺寸**（例如，单位μm）

如果这些参数未知，我们可以先进行假设，然后给出通用的计算公式。

---

### **关键参数定义**
1. **中间黑色大方格的物理尺寸**（假设由SLM生成）：
   - 方格像素数：`N × N`（例如，`32 × 32`）
   - SLM像素尺寸：`p_slm`（例如，10 μm）
   - 方格物理尺寸：`L_grid = N × p_slm`

2. **CCD相机参数**：
   - CCD像素尺寸：`p_ccd`（例如，3.45 μm，常见工业相机）
   - CCD分辨率：`W × H`（待计算）
   - CCD视场（FOV）：`FOV = (W × p_ccd, H × p_ccd)`

3. **目标**：
   - 中间方格占CCD视场的 **55%-65%**，即：
     - `L_grid = (0.55 ~ 0.65) × FOV_min`
     - 其中 `FOV_min` 是CCD视场的短边（假设方形视场，`FOV_min = min(W, H) × p_ccd`）

---

### **计算CCD分辨率**
#### **情况1：已知CCD像素尺寸 `p_ccd`**
如果CCD的像素尺寸已知（例如 `p_ccd = 3.45 μm`），则：
1. **计算CCD视场需求**：
   - 最小视场（65%占比）：`FOV_min = L_grid / 0.65`
   - 最大视场（55%占比）：`FOV_max = L_grid / 0.55`
2. **计算CCD分辨率**：
   - `W = ceil(FOV / p_ccd)`
   - `H = ceil(FOV / p_ccd)`（假设方形CCD）

#### **情况2：未知CCD像素尺寸，仅求比例关系**
如果CCD像素尺寸未知，但希望知道 **CCD分辨率与方格像素数的比例关系**：
- 由于 `L_grid = N × p_slm`，且 `FOV = M × p_ccd`（`M` 是CCD分辨率）
- 目标：`L_grid = (0.55 ~ 0.65) × FOV`
- 则：
  - `M = (N × p_slm) / ( (0.55 ~ 0.65) × p_ccd )`

---

### **MATLAB 计算示例**
假设：
- SLM方格大小 `N = 32` 像素
- SLM像素尺寸 `p_slm = 10 μm`
- CCD像素尺寸 `p_ccd = 3.45 μm`（如FLIR Blackfly相机）

```matlab
% 参数
```
