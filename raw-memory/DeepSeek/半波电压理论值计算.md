### 倍频法测量半波电压的详细原理与步骤

#### **1. 理论基础**
- **半波电压（\(V_\pi\)）**：使电光晶体输出的两偏振光产生 \(\pi\) 相位差的电压。
- **倍频现象**：当工作点位于光强调制曲线的极值点（极小值或极大值）时，输出信号的频率会变为调制信号频率的 **2倍**（即 \(2\omega\)）。
- **关键关系**：相邻两次倍频失真点对应的直流电压之差即为半波电压：
  \[
  V_\pi = |U_2 - U_1|
  \]
  其中 \(U_1\) 和 \(U_2\) 是相继出现倍频失真的直流电压值。

#### **2. 实验装置**
- **光路**：激光器 → 衰减片 → 电光晶体（LiNbO₃）→ 起偏器 → 检偏器 → 探测器。
- **电路**：
  - **调制信号源**：输出正弦交流电压（频率 \(\omega\)，通常选 1–10 kHz）。
  - **直流偏压源**：提供可调直流电压 \(V_{\text{dc}}\)（0–600 V）。
  - **探测器**：将光强信号转换为电信号，输出至示波器。
- **示波器连接**：
  - **CH1**：接调制信号源（显示原始调制波形）。
  - **CH2**：接探测器（显示解调后的输出波形）。

#### **3. 倍频法操作步骤**
1. **初始化设置**：
   - 调制信号选择 **内调**（使用内置信号源）。
   - 调制频率设为 **1 kHz**（典型值），调制幅度调至适中（约 10%）。
   - 激光功率衰减至 **<0.3 mW**（避免探测器饱和）。

2. **寻找第一次倍频失真**：
   - 缓慢旋转 **晶体高压** 旋钮，增加直流电压 \(V_{\text{dc}}\)。
   - 观察示波器 **CH2**（输出信号）波形：
     - **正常调制**：输出波形与 CH1 同频（\(\omega\)）。
     - **倍频失真**：输出波形频率变为 \(2\omega\)（如图 1-8）。
   - 记录此时电压 \(U_1\)（例如 \(U_1 = 120  \text{V}\))。

3. **寻找第二次倍频失真**：
   - 继续增加 \(V_{\text{dc}}\)，直至波形恢复同频调制。
   - 进一步增加电压，再次观察到倍频失真（频率 \(2\omega\)，如图 1-10）。
   - 记录此时电压 \(U_2\)（例如 \(U_2 = 380  \text{V}\))。

4. **计算半波电压**：
   \[
   V_\pi = |U_2 - U_1| = |380 - 120| = 260  \text{V}
   \]

5. **特殊处理（仅出现一次倍频时）**：
   - 若电压从 0 V 增至 600 V 仅出现一次倍频：
     - 将电源极性切换开关拨至 **负压** 模式。
     - 在负压区间（-600 V 至 0 V）寻找另一次倍频失真点。
   - 计算半波电压（例）：
     - 正压区倍频点 \(U_1 = 500  \text{V}\)
     - 负压区倍频点 \(U_2 = -240  \text{V}\)
     \[
     V_\pi = |500 - (-240)| = 740  \text{V} \quad \text{（需验证合理性）}
     \]

#### **4. 倍频现象的物理本质**
- **光强调制曲线**：输出光强 \(I\) 与直流偏压 \(V_{\text{dc}}\) 的关系为：
  \[
  I = I_0 \sin^2\left(\frac{\pi V_{\text{dc}}}{2V_\pi} + \phi_0\right)
  \]
- **极值点工作状态**：
  - 当 \(V_{\text{dc}} = 0, V_\pi, 2V_\pi, \ldots\) 时，曲线处于 **极小值点**。
  - 当 \(V_{\text{dc}} = \frac{V_\pi}{2}, \frac{3V_\pi}{2}, \ldots\) 时，曲线处于 **极大值点**。
- **倍频成因**：
  - 在极值点附近，调制信号的正负半周对称变化，导致输出信号频率翻倍（如图 1-6）。

\[

\]

- \(n_0 = 2.329\)（晶体折射率）

   V_\pi = \frac{1.56 \times 10^{-9}}{6.01 \times 10^{-12}} \approx 259.4  \text{V}

- **调制幅度**：不宜过大（建议 ≤30%），否则倍频失真易被掩盖。
- **噪声处理**：若波形抖动，启用示波器 **平均功能** 降噪。
