# 用户：

未退休的人每个月正常参保有医保返现吗？

# DeepSeek：

**原始回答**

对于未退休且正常参保的人来说，**通常是有医保返现的**（实际指个人账户入账）。目前全国基本统一，返现金额主要来自**你个人缴纳的那部分保费**。

*   **💰 返现标准怎么算？**
    在职职工（包括按此标准缴费的灵活就业人员）：**个人缴费基数的2%** 。单位缴纳的部分**不再**划入你的个人账户，全额进入统筹基金 。
    *   *举个例子*：若缴费基数为5000元，每月返100元（5000×2%）。

*   **⚠️ 注意特殊情况**
    *   **地区差异**：少数地区（如上海）可能按年一次性计入 。
    *   **参保身份**：部分地区以较低费率参保的灵活就业人员可能不设个人账户 。
