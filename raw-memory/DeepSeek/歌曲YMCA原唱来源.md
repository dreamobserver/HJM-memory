# 用户：

有人说ymca的原曲是日本人唱的对吗？

# DeepSeek：

**原始回答**

不对，《Y.M.C.A.》的原曲**不是日本人唱的**，它是由美国乐队演唱的经典迪斯科歌曲。

这里帮你梳理一下原唱和日本版本的渊源：

*   **原唱是美国组合**：歌曲原唱是美国的**Village People（村民乐队）**，于**1978年**发行。他们当时在舞台上是极具代表性的**角色装扮**（如警察、印第安酋长等）。
*   **日本是翻唱且极火**：你听到的日语版，是日本歌手**西城秀树**在**1979年**翻唱的《**YOUNG MAN (Y.M.C.A.)**》。这首歌在日本**爆红**，销量非常高，他设计的招牌手势也风靡一时。所以很多人会误以为这是日本原唱。

这首歌的累计销量超过了**1200万份**，还曾在包括英国在内的**15个国家**拿下排行榜冠军，非常厉害。
