# 用户：

什么是pcb沉金

# DeepSeek：

**原始回答**

PCB沉金（Electroless Nickel Immersion Gold，ENIG）是一种常见的印刷电路板（PCB）表面处理工艺，通过在铜焊盘上化学沉积镍层和金层，提供良好的焊接性、抗氧化性和耐磨性。以下是其核心要点：

### **1. 沉金工艺步骤**
- **清洁铜表面**：去除氧化层和油污，确保结合力。
- **微蚀刻**：粗化铜面，增强镍层附着力。
- **沉镍（化学镀镍）**：通过化学反应在铜上沉积3-6μm的镍磷合金层（含磷4-10%），作为金层的基底。
- **沉金（置换金）**：在镍层上置换出0.05-0.1μm的薄金层，防止镍氧化，保证焊接性能。

### **2. 沉金的作用**
- **抗氧化**：金层保护镍层不生锈。
- **焊接性**：金层提升焊盘与焊料的结合力。
- **耐磨性**：镍层提供硬度，适合多次插拔或接触式连接（如金手指）。
- **平整度**：适合高密度焊盘（如BGA封装）。

### **3. 优缺点**
- **优点**：
  - 表面平整，适合精细间距元件。
  - 长期稳定性好，适合长期存储。
  - 兼容多种焊接工艺（如锡焊、压接）。
- **缺点**：
  - 成本较高（相比喷锡、OSP）。
  - 可能出现“黑盘问题”（镍层过度腐蚀导致焊接不良）。

### **4. 应用场景**
- 高可靠性电子产品（如医疗、航空航天）。
- 高频高速电路（金层信号损耗小）。
- 需要多次插拔或长期保存的PCB。

### **5. 与其他工艺对比**
- **喷锡（HASL）**：成本低但平整度差，不适用高密度设计。
- **OSP（有机保护膜）**：廉价但不耐存储，焊接次数有限。
- **电镀金**：金层更厚，成本更高，用于特殊需求（如金手指）。

### **总结**
沉金工艺平衡了性能与成本，是现代PCB（尤其是高精度、高可靠性产品）的主流选择之一，但需根据具体需求（如预算、焊接方式）权衡其他表面处理方案。
