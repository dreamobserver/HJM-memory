光纤外面包裹的塑料外皮橙色与黄色哪一个是单模哪一个是多模

这是一个非常好的问题，也是网络布线中一个常见的混淆点。

简单直接的回答是：

*   **黄色外皮**通常代表 **单模光纤**
*   **橙色外皮**通常代表 **多模光纤**

---

### 详细解释和区分

为了更清晰地理解，我们来看一下它们的对比表格：

| 特性 | 单模光纤 | 多模光纤 |
| :--- | :--- | :--- |
| **典型外皮颜色** | **黄色** | **橙色** (最常见)、**水蓝色** (OM3/OM4万兆)、**青绿色** (OM5) |
| 光传输方式 | 单一模式（一种光路） | 多种模式（多种光路） |
| 核心直径 | 非常细，约 8-10 µm | 较粗，约 50 µm 或 62.5 µm |
| 光源 | 激光 | 大多使用LED（早期）或VCSEL激光 |
| 传输距离 | 非常远，可达数十至上百公里 | 较短，通常几百米到两公里 |
| 带宽 | 极高 | 高，但低于单模 |
| 成本 | 设备（光模块）较贵，光纤本身便宜 | 设备（光模块）较便宜，光纤本身稍贵 |
| 主要应用 | 电信骨干网、长途通信、有线电视 | 数据中心、企业局域网、楼宇内部布线 |

---

### 为什么颜色很重要？

颜色的标准化是为了让工程师、技术人员在现场施工和维护时能够快速、准确地识别光纤类型，从而：

1.  **避免混用**：绝对不能将单模设备（使用激光）连接到多模光纤上，反之亦然。这会导致信号无法传输，甚至可能损坏设备。
2.  **提高效率**：一眼就能分辨，无需借助仪器测量。
3.  **标准化管理**：有利于大型数据中心的规范化布线和管理。

### 重要补充：多模光纤的其他颜色

虽然橙色是多模光纤最经典和最常见的颜色，但随着技术的发展，为了区分不同性能等级的多模光纤，也引入了其他颜色：

*   **橙色 (Orange)**： 通常是 **OM1** 和 **OM2** 光纤，用于百兆、千兆以太网。
*   **水蓝色 (Aqua)**： 通常是 **OM3** 和 **OM4** 光纤，是优化后的激光优化多模光纤，主要用于万兆（10G）、四万兆（40G）和十万兆（100G）以太网。
*   **青绿色 (Lime Green)**： 是 **OM5** 光纤（宽波多模光纤），设计用于更高速度的短波分复用技术。

### 总结

记住最基本的原则：

*   **见黄思远（单模）**：看到**黄色**，就想到传输距离**远**的**单模光纤**。
*   **见橙思多（多模）**：看到**橙色**，就想到用于短距离、模式**多**的**多模光纤**。

在实际操作中，除了看颜色，最好再检查一下光纤线缆上印制的型号文字，进行双重确认。
