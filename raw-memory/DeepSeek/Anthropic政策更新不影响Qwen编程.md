🧠 **CCR 如何工作？**

CCR 的核心工作原理可以概括为以下几点：
1.  **拦截请求**：当你通过 Claude Code CLI 发出请求时，CCR 会拦截本应发送给 Anthropic 官方 API 的请求。
2.  **智能路由**：根据你预先在配置文件 (`config.json`) 中设置的规则，CCR 会决定将请求转发给哪个模型提供商。路由规则可以基于任务类型（如默认对话、后台任务、深度思考、长上下文处理、网络搜索等）。
3.  **格式转换**：不同模型提供商的 API 接口格式可能不同。CCR 内置的 **Transformer** 系统会自动进行转换，确保请求和响应能被正确理解。
4.  **返回结果**：CCR 获取目标模型的响应后，会将其转换回 Claude Code 兼容的格式并返回给你。
