5.  **确定修改方案**

## 第二步：实施修改（两种方法）

### 方法一：直接二进制修补（使用HxD）

如果通过Ghidra找到了确切的字节码位置和修改方式，这是最直接的方法。

1.  **在Ghidra中定位机器码**：
    *   在反编译窗口中找到关键判断的代码行。
    *   切换到对应的汇编视图（Listing window），找到这些指令的二进制机器码及其文件偏移地址（**`RAM`** 地址和 **`File Offset`** 可能不同，注意转换）。

2.  **计算文件偏移**：
    *   假设Ghidra告诉你关键跳转在虚拟地址（VA）`0x140001234`。
    *   在Ghidra的**程序树**中查看该段（如`.text`）的`File Offset`和`Virtual Address`。
    *   **文件偏移 = (VA - 虚拟地址起始) + 文件偏移起始**

3.  **使用HxD修改**：
    *   用HxD以管理员身份打开目标EXE或DLL文件。
    *   按 `Ctrl+G`，输入计算出的**文件偏移地址**，跳转到该位置。
    *   **常见修改**：
        *   **跳过错误**：将条件跳转（如 `74 15` `JZ 0x15`）修改为无条件跳转（`EB 15` `JMP 0x15`）或直接NOP掉（`90 90`）。
        *   **强制成功**：找到设置返回值的指令（如 `B8 01 00 00 00` `MOV EAX,1`），确保它总是被执行。

4.  **保存备份**：修改前务必在HXd中 **`File` -> `Save As`** 备份原始文件！

| 方法 | 优点 | 缺点 | 适用场景 |

# api_hook_monitor.py
import frida
import sys
import json
from datetime import datetime

class SerialAPIHook:
    def __init__(self):
        self.log_data = []
        self.log_file = f"api_hook_log_{datetime.now().strftime('%Y%m%d_%H%M%S')}.json"
        
    def on_message(self, message, data):
        """处理Frida接收到的消息"""
        if message['type'] == 'send':
            payload = message['payload']
            self.log_data.append({
                'timestamp': datetime.now().isoformat(),
                'type': payload.get('type', 'unknown'),
                'function': payload.get('function', 'unknown'),
                'data': payload.get('data', ''),
                'direction': payload.get('direction', 'unknown')
            })
            print(f"{payload['direction']} {payload['function']}: {payload['data']}")
            
            # 定期保存
            if len(self.log_data) % 10 == 0:
                self._save_log()
    
    def _save_log(self):
        """保存日志"""
        with open(self.log_file, 'w', encoding='utf-8') as f:
            json.dump(self.log_data, f, indent=2, ensure_ascii=False)
    
    def hook_serial_functions(self, target_process):
        """Hook串口相关函数"""
        js_code = """
        // Hook Windows API 串口函数
        const kernel32 = Process.getModuleByName('kernel32.dll');
        const CreateFileA = kernel32.getExportByName('CreateFileA');
        const WriteFile = kernel32.getExportByName('WriteFile');
        const ReadFile = kernel32.getExportByName('ReadFile');
        
        // Hook CreateFileA 来检测串口打开
        Interceptor.attach(CreateFileA, {
            onEnter: function(args) {
                this.filename = Memory.readUtf8String(args[0]);
                if (this.filename.includes('COM')) {
                    send({
                        type: 'serial_open',
                        function: 'CreateFileA',
                        filename: this.filename,
                        direction: 'open'
                    });
                }
            }
        });
        
        // Hook WriteFile 来监控发送数据
        Interceptor.attach(WriteFile, {
            onEnter: function(args) {
                this.handle = args[0];
                this.buffer = args[1];
                this.length = args[2].toInt32();
                
                if (this.length > 0) {
                    this.data = Memory.readByteArray(this.buffer, this.length);
                    send({
                        type: 'serial_write',
                        function: 'WriteFile',
                        data: Array.from(this.data),
                        direction: 'TX',
                        length: this.length
                    });
                }
            }
        });
        
        // Hook ReadFile 来监控接收数据
        Interceptor.attach(ReadFile, {
            onEnter: function(args) {
                this.handle = args[0];
                this.buffer = args[1];
                this.length = args[2].toInt32();
            },
            onLeave: function(retval) {
                if (retval.toInt32() > 0) {
                    var bytesRead = parseInt(Memory.readUInt(this.length));
                    if (bytesRead > 0) {
                        var data = Memory.readByteArray(this.buffer, bytesRead);
                        send({
                            type: 'serial_read',
                            function: 'ReadFile',
                            data: Array.from(data),
                            direction: 'RX',
                            length: bytesRead
                        });
                    }
                }
            }
        });
        """
        
        try:
            session = frida.attach(target_process)
            script = session.create_script(js_code)
            script.on('message', self.on_message)
            script.load()
            print(f"已附加到进程 {target_process}，开始监控串口API调用...")
            sys.stdin.read()
        except Exception as e:
            print(f"Hook失败: {e}")

import struct
import json
from datetime import datetime
import csv

class SPMAnalyzer:
    def __init__(self, spm_file):
        self.spm_file = spm_file
        self.packets = []
        
    def parse_spm_file(self):
        """尝试解析.spm文件"""
        try:
            with open(self.spm_file, 'rb') as f:
                # .spm文件有特定的二进制格式，需要反向工程
                print("尝试解析.spm文件...")
                
                # 读取文件头（通常是文件格式标识）
                header = f.read(4)
                print(f"文件头: {header.hex()}")
                
                # 尝试不同的解析方法
                packets = []
                position = 0
                
                while True:
                    # 尝试读取数据包长度（假设有长度字段）
                    try:
                        # 常见的串口监控数据包结构可能包含：
                        # 时间戳(8字节) + 方向(1字节) + 数据长度(2字节) + 数据
                        packet_header = f.read(11)
                        if len(packet_header) < 11:
                            break
                            
                        # 解析时间戳（可能是Windows FILETIME格式）
                        timestamp = struct.unpack('<Q', packet_header[0:8])[0]
                        direction = packet_header[8]  # 0=TX, 1=RX?
                        data_length = struct.unpack('<H', packet_header[9:11])[0]
                        
                        # 读取数据
                        data = f.read(data_length)
                        
                        packet = {
                            'timestamp': self._filetime_to_datetime(timestamp),
                            'direction': 'TX' if direction == 0 else 'RX',
                            'data': data.hex().upper(),
                            'length': data_length
                        }
                        packets.append(packet)
                        
                    except Exception as e:
                        print(f"解析数据包时出错: {e}")
                        break
                
                self.packets = packets
                return packets
                
        except Exception as e:
            print(f"解析文件失败: {e}")
            return []
    
    def _filetime_to_datetime(self, filetime):
        """将Windows FILETIME转换为datetime"""
        # Windows FILETIME是1601年1月1日以来的100纳秒间隔数
        try:
            epoch = datetime(1601, 1, 1)
            microseconds = filetime // 10  # 转换为微秒
            return epoch + timedelta(microseconds=microseconds)
        except:
            return datetime.now()
    
    def export_to_csv(self, output_file):
        """导出到CSV文件"""
        if not self.packets:
            print("没有数据可导出")
            return False
            
        try:
            with open(output_file, 'w', newline='', encoding='utf-8') as csvfile:
                fieldnames = ['timestamp', 'direction', 'data_hex', 'data_length', 'data_ascii']
                writer = csv.DictWriter(csvfile, fieldnames=fieldnames)
                
                writer.writeheader()
                for packet in self.packets:
                    data_ascii = ''.join([chr(b) if 32 <= b <= 126 else '.' for b in bytes.fromhex(packet['data'])])
                    writer.writerow({
                        'timestamp': packet['timestamp'].isoformat(),
                        'direction': packet['direction'],
                        'data_hex': packet['data'],
                        'data_length': packet['length'],
                        'data_ascii': data_ascii
                    })
            
            print(f"成功导出到: {output_file}")
            return True
            
        except Exception as e:
            print(f"导出CSV失败: {e}")
            return False
