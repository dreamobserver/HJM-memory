# 用户：

愿大家，多喜乐，常安宁是是谁的话

# DeepSeek：

**原始回答**

“愿大家，多喜乐，常安宁”这一祝福语，其形成与流行经历了从文学创作到官方引用再到大众传播的过程，具体脉络如下：

### 📜 一、文学溯源：金庸《天龙八部》中的原型  
“多喜乐”与“长安宁”最早见于金庸小说《天龙八部》（1963年）。书中角色阮星竹为两个女儿打造的金锁上刻有寄语：  
- **阿朱的金锁**："天上星，亮晶晶，永灿烂，长安宁"  
- **阿紫的金锁**："湖边竹，绿盈盈，报平安，多喜乐" 。  
此处的“长安宁”“多喜乐”承载了对子女平安喜乐的祈愿，成为后世化用的灵感来源。

### 🕉️ 二、文化融合：佛教祝祷的演变  
- **“所求皆如愿”** 源自佛教典籍《大随求陀罗尼心咒》的汉译“一切行愿皆悉满足”，后简化为“所求皆如愿”。  
- 民间将佛教祝语与金庸的短语结合，形成完整祝福链：**“所求皆如愿，所行化坦途，多喜乐，长安宁”**，寓意生活顺遂、心境平和。

### 🎤 三、官方引用：习近平2025年新年贺词  
2024年12月31日，习近平主席发表2025年新年贺词，以“**祝大家所愿皆所成，多喜乐、长安宁！**”作结。这一表述：  
1. **融合传统与现代**：既呼应金庸的文学意象，又衔接佛教对“如愿”的追求；  
2. **赋予时代内涵**：在贺词中与“祝祖国时和岁丰、繁荣昌盛”并列，将个人祝愿与国家愿景相统一。  
此举使该句从文学符号升华为公共祝福，引发广泛传播。

### 🌆 四、大众化传播：节日场景与城市景观  
- **2025年春节**，重庆地标建筑（如江北嘴十联屏、解放碑WFC）以巨幅灯光展示“**多喜乐，长安宁**”“一路长安”等字样，成为网红打卡点。民众拍照转发，使其融入春节祝福场景。  
- 网络祝福语中常见变体如“**愿新年，胜旧年，多喜乐，常安宁**”，用于表达对亲友的岁末祈愿。

### 💎 总结：谁的“话”？  
- **原创性**：单字组合并非独创，但“多喜乐，长安宁”的短语定型源于金庸。  
- **推广者**：习近平在新年贺词中的引用是其进入主流视野的关键节点，赋予官方认可度。  
- **传播主体**：大众在节日祝福、社交媒体中的自发使用，使其成为当代文化符号。  

因此，这句话是**集体创作的结果**：金庸奠定文学基础，民间糅合佛教祝语，官方赋予权威声量，民众推动日常化应用。其生命力正源于多重文化基因的交融。
