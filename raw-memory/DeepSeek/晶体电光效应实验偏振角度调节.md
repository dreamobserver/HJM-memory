# DeepSeek：

**原始回答**

在实验1中，当调节起偏器和检偏器的角度，使干涉图的暗十字互相垂直且各自在水平和竖直方向时（如图1-8.1所示），此时起偏器与检偏器的偏振方向是互相垂直的。具体角度关系如下：

1. **起偏器**的偏振方向通常设置为水平方向（0度）。
2. **检偏器**的偏振方向则与起偏器垂直，即设置为竖直方向（90度）。

因此，起偏器与检偏器的偏振方向之间的夹角为 **90度**。这种正交配置（一个水平、一个竖直）是实验中常见的偏振光干涉观察条件，能够确保两束偏振光的振动方向完全垂直，从而形成清晰的暗十字干涉图案。
