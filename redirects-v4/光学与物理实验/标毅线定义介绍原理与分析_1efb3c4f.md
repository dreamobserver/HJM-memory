# 标毅线定义介绍原理与分析

## 原始对话

# 用户：

什么是标毅线

# DeepSeek：

**原始回答**

“标毅线”是杭州户外圈一条极具挑战性的经典徒步路线，全称是**西湖标准毅行线**。它被很多驴友看作是**杭州户外入门“毕业线”**。

这条线路的具体情况如下：

*   **路线概览**：从**老和山**出发，串联起**北高峰**、**天竺山**、**五云山**、**玉皇山**等20多座山峰，最终抵达**吴山**，几乎把西湖群山走了个遍。
*   **核心数据**：总长约 **25公里**，累计爬升约 **1700米**，一般走完全程需要 **6到9小时**。
*   **名称由来**：一方面因为它是一条“标准”的毅行参考线；另一方面也很考验徒步者的**毅力**是否“达标”。
