### 正确导出步骤：

2. **选择导出**：点击菜单栏的 `File` -> `Export` 
3. **选择格式**：通常可以选择：
   - `Text file (*.txt)`
   - `CSV file (*.csv)`
   - `Excel file (*.xlsx)`
4. **设置导出选项**：确保包含时间戳、方向、数据等所有信息
