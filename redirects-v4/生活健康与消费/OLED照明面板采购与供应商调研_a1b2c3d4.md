# OLED照明面板采购与供应商调研

## 问题摘要

本切片围绕OLED照明面板采购展开。起始诉求是采购OLED照明面板打样，但面临台湾专利壁垒。调研了Lumiotec（已倒闭）、OLEDWorks（美国，有中国渠道）、以及国内厂商苏州方昇光电（设备为主）、江苏壹光（面板）、南京第壹有机光电（面板）的适用性。最终建议从小批量采购国内厂商面板入手，专利风险由供应商承担。

## 原始对话

### Turn 1
#### 👤 User

我需要采购 OLED 照明面板，但听说有台湾专利问题。帮我调研一下供应商情况，尤其是 Lumiotec 和 OLEDWorks。

#### 🤖 Assistant

陛下！臣这就去查 OLED 照明面板的供应商和专利情况！

**Lumiotec 状态**：已倒闭/停止运营。这家日本 OLED 照明厂商早在几年前就已停止业务。

**OLEDWorks**：
- 美国公司，总部在纽约罗切斯特
- 主要做 OLED 照明面板，技术实力强
- 有中国渠道/代理，可以通过国内经销商采购

**台湾专利问题**：
OLED 照明领域确实存在专利壁垒。主要专利持有方包括 UDC（磷光 OLED 核心专利）、陶氏/杜邦（材料专利）、出光兴产（材料专利）。台湾厂商也有部分专利布局。

### Turn 2
#### 👤 User

详细说一下 OLEDWorks 的中国渠道怎么联系？他们有没有代理商在国内？

#### 🤖 Assistant

OLEDWorks 在中国主要通过代理商和分销商网络进行销售。建议官网提交询盘 (www.oledworks.com) 或直接邮件联系。OLEDWorks 更偏向 B2B 大客户模式，小批量采购可能需要通过代理商。

### Turn 3
#### 👤 User

打样用的，不需要大批量。另外帮我查查 Lumiotec 倒闭之后他们的技术或者专利去哪儿了。

#### 🤖 Assistant

Lumiotec 停业后，部分技术和专利被 Kaneka（钟化）收购。打样采购建议国内厂商：苏州方昇光电、江苏壹光、南京第壹有机光电。

### Turn 4
#### 👤 User

好，帮我都查一下这三家的情况。

#### 🤖 Assistant

- **苏州方昇光电**：2008年成立，主营OLED镀膜设备、真空蒸镀设备，偏设备而非面板
- **江苏壹光科技**：OLED照明面板研发与生产，适合小批量采购打样
- **南京第壹有机光电**：有机光电材料与器件研发，有自有技术路线

建议优先联系江苏壹光和南京第壹有机光电询价。

### Turn 5
#### 👤 User

OLED 照明面板的台湾专利具体是什么情况？

#### 🤖 Assistant

核心专利包括UDC磷光专利、材料专利（出光兴产/陶氏/默克）、器件结构专利。台湾友达、群创等有相关专利但不如显示领域密集。规避策略：从中国大陆厂商采购面板，由供应商承担专利风险。

## 关键结论

OLED照明面板采购的最佳路径是联系国内厂商（江苏壹光、南京第壹有机光电）进行小批量打样，避开台湾专利壁垒。Lumiotec已倒闭，其专利和技术部分流向Kaneka。OLEDWorks有中国渠道但更适合大客户。苏州方昇光电主要为设备商，不直接生产面板。
