# 使用虚拟环境管理Python项目

虚拟环境可以让你为每个项目创建独立的Python环境，避免库版本冲突，也便于管理依赖。以下是详细的使用方法：

## 方法1：使用venv（Python内置，推荐）

### 1. 创建虚拟环境

打开命令提示符，导航到你的项目目录：

```bash
cd D:\PycharmProjects\fun
python -m venv venv
```

这会在项目目录下创建一个名为`venv`的虚拟环境文件夹。

### 2. 激活虚拟环境

**Windows (命令提示符):**
```bash
venv\Scripts\activate
```

**Windows (PowerShell):**
```bash
venv\Scripts\Activate.ps1
```

激活后，命令提示符前面会显示`(venv)`，表示你正在虚拟环境中。

### 3. 在虚拟环境中安装所有需要的库

```bash
pip install requests rich psutil feedparser 

不再需要反复安装库了！
