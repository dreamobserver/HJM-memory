**病因诊断：**
这就好比两个不同方言的人在吵架。

- **软件（LCOS-SLM）**：它是用“简体中文编码” (通常是 GB2312 或 GBK) 写的“老古董”程序。它心里想的是简体字。
- **系统（您的电脑）**：目前是 **繁体中文 (Big5)** 的非 Unicode 环境。
- **结果**：软件递过来一个代码，系统按繁体字典一查——“查无此人”，于是就愤怒地弹出了一个个问号 `?`。如果是乱码（比如 `锟斤拷` 或古怪汉字）那是读错了，如果是 `?`，通常是彻底读不出来。

### 💊 献给陛下的两剂解药
陛下，这问题好治！不用重装系统，也不用把电脑扔进火炉！小的为您准备了上、下两策：

#### 方案一：一劳永逸法（修改非 Unicode 区域设置）👉 **最推荐**
这个方法是让系统在运行这种“不懂事”的老软件时，强制假装自己是简体中文环境。

1. 按下 `Win` 键，输入 **“控制台”** (Control Panel) 并打开。
2. 找到 **“时钟和区域”** (Clock and Region) -> **“区域”** (Region)。
3. 点击顶部的 **“管理”** (Administrative) 标签页。
4. 陛下请看最下面有一个 **“非 Unicode 程序的语言”** (Language for non-Unicode programs)。
5. 点击 **“变更系统地区设定”** (Change system locale)。
6. **关键一步**：在下拉菜单里，把当前的“中文（繁体，台湾）” 改成 **“中文（简体，中国）”**。
  - *注意：那个“Beta 版: 使用 Unicode UTF-8...” 的勾选框千万不要勾！勾了这老软件可能死得更惨！*
7. 点击确定，系统会要求 **重启**。
8. **重启**后，这只“独角兽”就驯服了，问号就会变回简体中文！
⚠️ 小的的碎碎念： 改了这个设置后，某些极个别的繁体老软件可能会乱码，但在现代 Windows 10 上，绝大多数软件（浏览器、Office等）都是纯 Unicode 的，完全不受影响。为了这台 LCOS 设备，这是最稳妥的！
#### 方案二：特权特办（使用 Locale Emulator）
如果您不想重启，或者不想改系统的“户籍”，可以用这个第三方小工具。

1. 去 GitHub 下载一个叫 **Locale Emulator (LE)** 的神器。
2. 安装后，右键点击这个乱码软件的图标。
3. 选择 `Locale Emulator` -> `Run in Simplified Chinese (Admin)`。
4. 它就会给这个软件单独制造一个简体的幻觉，而不影响系统其他部分。
