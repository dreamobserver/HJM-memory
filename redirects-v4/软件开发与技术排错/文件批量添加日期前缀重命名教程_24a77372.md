### 🐍 方案一：Python 自动改名脚本 (最稳妥)
陛下，您只需要把下面这段代码保存为 `.py` 文件，放在和这些 `05-XX` 文件 **同一个文件夹里** 运行即可。

```python
import os

# 陛下，这是您要的前缀
prefix = "(2026-01-26)"

# 获取当前脚本所在的文件夹路径
# 小的自动识别您把脚本放在哪，不用您操心路径！
current_folder = os.getcwd()

# 计数器，以此向陛下邀功
count = 0

print("---------- 小的开始干活了 ----------")

# 遍历文件夹里的所有文件
for filename in os.listdir(current_folder):
    # 1. 必须是txt文件 (根据截图判断)
    # 2. 名字里不能已经包含这个前缀 (防止陛下手抖运行两次，小的得预判您的预判)
    # 3. 排除脚本自己 (小的不能把自己也改名了)
    if filename.endswith(".txt") and prefix not in filename:
        
        # 构造旧名字和新名字
        old_name = filename
        new_name = prefix + filename
        
        try:
            # 执行改名！
            os.rename(
                os.path.join(current_folder, old_name),
                os.path.join(current_folder, new_name)
            )
            print(f"✅ 已处理: {old_name} -> {new_name}")
            count += 1
        except Exception as e:
            print(f"❌ 吓死小的了，文件 {filename} 改名失败：{e}")

print("------------------------------------")
print(f"🎉 报告陛下！一共处理了 {count} 个文件！")

input("按回车键结束，小的退下了...")

```

### 🐍 方案一：Python “整容”脚本 (精准切除术)
陛下，这个脚本会专门寻找文件名里的 `(2026-01-26)` 这一段，然后把它变成一个优雅的横杠 `-`。
**逻辑是这样的：**`2026-01-26` + `(2026-01-26)` + `05-1`
⬇️ 替换后
`2026-01-26` + `-` + `05-1`
请把这个存为 `fix_name.py` 放在同级目录下运行：

```python
import os

# 陛下，这是我们要切除的病灶（多余的括号部分）
target_str = "(2026-01-26)"
# 这是要替换成的东西（一个横杠）
replace_with = "-"

current_folder = os.getcwd()
count = 0

print("---------- 🚑 急诊手术开始 ----------")

for filename in os.listdir(current_folder):
    # 只处理包含那个怪异括号组合的 .txt 文件
    if filename.endswith(".txt") and target_str in filename:
        
        old_name = filename
        # 执行替换手术：把 "(2026-01-26)" 变成 "-"
        new_name = filename.replace(target_str, replace_with)
        
        try:
            os.rename(
                os.path.join(current_folder, old_name),
                os.path.join(current_folder, new_name)
            )
            print(f"✅ 修复成功: {old_name} \n   -> 变成: {new_name}")
            count += 1
        except Exception as e:
            print(f"❌ 救命啊，文件 {filename} 卡住了：{e}")

print("------------------------------------")
print(f"🎉 陛下！一共修复了 {count} 个文件！")
print("现在的格式应该是：2026-01-26-05-1 (看着顺眼多了！)")
input("按回车键结束，小的去面壁思过了...")

```

### ⚡ 方案二：PowerShell 一行流 (如果您现在只想快点解决)
如果是刚才那个 PowerShell 窗口还没关，直接复制这一句（注意，这次用到了正则替换，因为要处理括号）：

```powershell
Get-ChildItem *.txt | Rename-Item -NewName { $_.Name -replace "\(2026-01-26\)", "-" }

```
**原理解析：**

- `\(2026-01-26\)`：告诉电脑，“括号”是文字，不是代码，给我精准找到这段话。
- `"-"`：把它换成横杠。

### 🐍 方案一：Python 完美拼接脚本
陛下，这个脚本会把 `01-1.txt` 变成 `2026-01-23-01-1.txt`。
请把下面代码保存为 `add_prefix_0123.py`，放到截图里那个文件夹运行。

```python
import os

# 陛下，这次的前缀小的给您加了横杠，保证不粘连！
prefix = "2026-01-23-"

current_folder = os.getcwd()
count = 0

print("---------- 🛠️ 正在为您加装时间戳 ----------")

for filename in os.listdir(current_folder):
    # 只处理 txt 文件，且排除脚本自己，且防止重复添加
    if filename.endswith(".txt") and not filename.startswith("2026-01-23"):
        
        old_name = filename
        # 直接拼接：前缀 + 原文件名
        new_name = prefix + filename
        
        try:
            os.rename(
                os.path.join(current_folder, old_name),
                os.path.join(current_folder, new_name)
            )
            # 输出格式：01-1.txt -> 2026-01-23-01-1.txt
            print(f"✅ 搞定: {old_name} -> {new_name}")
            count += 1
        except Exception as e:
            print(f"🥶 陛下救命，文件 {filename} 报错了：{e}")

print("------------------------------------------")
print(f"🎉 陛下，{count} 个文件处理完毕！")
print("现在的样子应该是：2026-01-23-01-1.txt")
input("按回车键结束，小的退下了...")

```
