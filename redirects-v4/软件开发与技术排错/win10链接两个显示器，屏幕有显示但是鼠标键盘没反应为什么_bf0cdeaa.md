# DeepSeek：

**原始回答**

当Windows 10连接双显示器后出现屏幕显示正常但鼠标键盘无响应的情况，可能是由于多种原因导致的。以下是逐步排查和解决问题的方案：

---

### **一、检查硬件连接**
1. **重新插拔外设**  
   - 拔下鼠标和键盘的USB接口，更换其他USB端口（优先使用主板后置接口，避免使用扩展坞或前置面板）。
   - 如果是无线设备，检查电池电量或接收器连接。

2. **排除接口故障**  
   - 尝试将键鼠连接到其他电脑，确认设备是否正常。
   - 使用其他键鼠测试当前电脑的USB接口是否可用。

3. **检查显示器扩展坞问题**  
   - 如果通过显示器内置的USB Hub连接外设，尝试直接连接电脑的USB接口（某些显示器Hub可能存在供电不足或兼容性问题）。

1. **排查HDMI线缆或接口故障**

# 用户：

win10链接两个显示器，屏幕使用扩展有显示但是没有办法在主屏幕上显示只在副屏上显示为什么

# DeepSeek：

**原始回答**

当 Windows 10 连接双显示器并设置为扩展模式时，主屏幕无显示而仅副屏显示，通常是由于 **主显示器设置错误** 或 **显卡驱动/信号分配问题** 导致。以下是逐步排查和解决方案：

---

### **一、检查显示设置**
1. **确认主显示器设置**  
   - 右键桌面 → **显示设置** → 在“显示布局”界面中，**拖动的显示器图标**代表实际物理位置。  
   - **点击标识显示器**（系统会显示数字标记），确认哪个是主屏（标记为 **“1”** 的显示器）。  
   - 如果主屏错误设置为副屏：  
     → 选中主屏对应的显示器图标 → 勾选 **“设为主显示器”** → 点击 **“应用”**。

   ![显示设置示例](https://i.imgur.com/5cR0xKp.png)

2. **调整显示器排列顺序**  
   - 如果显示器图标排列与实际物理位置不符（例如主屏在左但图标在右），可能导致鼠标无法移动到主屏。  
   → 拖动显示器图标调整位置，使其与实际摆放一致。
