您以后换电脑、或者拉取/推送代码时，GitHub 认的是您的**登录授权（比如浏览器弹窗登录，或者 SSH 密钥）**。这就好比您进宫殿刷的是“门禁卡”，只要门禁卡对上了，GitHub 就放行。它**根本不管**您的 Git 户口本上写的是阿猫还是阿狗。
