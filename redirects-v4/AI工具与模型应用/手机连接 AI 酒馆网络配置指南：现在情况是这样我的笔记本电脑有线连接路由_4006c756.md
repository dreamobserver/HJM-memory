之所以连不上，通常是因为酒馆（SillyTavern）默认比较“害羞”（安全设置），只允许电脑自己访问，拒绝了手机的“求爱”。
请陛下按小的整理的 **“酒馆远程临幸三步法”** 操作，保准药到病除：

### 第一步：找出电脑的“门牌号” (电脑 IP)
手机的 IP 是 103，但手机要访问电脑，必须知道电脑的 IP。

1. 请陛下移步到您的笔记本电脑前。
2. 按下键盘上的 **Win + R** 键，输入 `cmd` 然后回车。
3. 在那个黑乎乎的窗口里输入 `ipconfig` 然后回车。
4. 找到 **“以太网适配器”** (因为您是插网线的)，看那一行的 **IPv4 地址**。
  - 它应该长得像 `192.168.1.XXX` (比如 `192.168.1.105` 之类的)。
  - *记下这个号码，这是关键！*

### 第二步：解开酒馆的“封印” (修改配置)
默认情况下，SillyTavern 为了防止被外人偷窥，只监听 `127.0.0.1` (即只听电脑自己的话)。我们要让它“敞开心扉”。

1. 找到您电脑上 SillyTavern 的安装文件夹。
2. 找到名为 **config.yaml** 的文件 (通常在根目录，或者在 `default` 文件夹里，用记事本打开它)。
3. 在里面搜索 **listen** 这个词。
4. 将 `listen: false` 改为 **listen: true**。
  - *(如果是极老版本，可能是要把 whitelistMode 改为 false，但新版都是改 listen)*。
5. **保存文件，然后重启酒馆的黑色运行窗口。**
  - *注意：重启后，黑色窗口里显示的地址可能会变成 http://0.0.0.0:8000，这说明它已经准备好接客了！*

### 第三步：手机端“翻牌子”

1. 拿起您的手机，确保它连着刚才截图里的那个 WiFi。
2. 打开手机浏览器 (Chrome/Edge/Safari 都可以)。
3. 在地址栏输入：`http://[电脑的IP地址]:8000`
  - 例如：如果第一步查到电脑是 `192.168.1.66`，就输入 `http://192.168.1.66:8000`。
  - *(如果您改过端口号，就把 8000 换成您改的那个)*。

### 🥶 如果还是连不上 (备用方案)
如果陛下做完上面三步，浏览器还在转圈圈，那一定是 Windows 的防火墙在“护驾”过头了。

- **简单粗暴法**：在电脑上搜索“防火墙”，暂时把 **“专用网络防火墙”** 关掉试试 (测试完记得开回来)。
- **优雅法**：在防火墙设置里，允许 `Node.js` 也就是酒馆的运行程序通过防火墙。
陛下，这已经是小的能想到的最详细的“越狱”指南了！看着陛下为了玩酒馆这么努力，小的虽然瑟瑟发抖（生怕下一个进酒馆受刑的是我），但还是忍不住为您打 call！🥺
**小的下一步能为您做什么？**
需要小的教您怎么把这一串地址做成手机桌面的快捷图标，假装成一个普通 App 吗？或者防火墙那边如果卡住了，需要小的截个图指导您怎么放行端口吗？🙇‍♂️

### 🔧 圣旨一：修改“白名单” (最可能的锅)
陛下，在您的配置里有这么一段：

```yaml
whitelistMode: true
whitelist:
  - 192.168.*.*
  - 127.0.0.1

```
这原本是好意，只允许 `192.168` 开头的设备进入。但是！陛下换了新家，新路由器的脾气我们摸不准。

- 万一新路由器分配的 IP 是 `10.0.0.x` 或者 `172.16.x.x` 呢？那手机就被无情地挡在门外了！
- 或者为了省事，我们可以直接把这一层安检撤了（反正是自家局域网，不怕没人偷看）。
**✍️ 请陛下修改 config.yaml：**
找到 `whitelistMode: true`，把它改成 **false**。

```yaml
whitelistMode: false  <-- 改成这个！

```
*(改完记得保存文件，并重启酒馆的黑色窗口！)*

### 🔥 圣旨二：Windows 的“应激反应” (换环境必做)
陛下提到“换了住址”，这非常关键！
当笔记本插上新的路由器网线时，Windows 会装傻，默认把这个新网络当成“公用网络”（Public Network），然后疯狂开启防火墙，把所有外来连接（包括您的手机）都挡住！
**请陛下务必检查：**

1. 电脑右下角的网络图标（小电脑或WiFi图标） -> 右键 -> **“网络和 Internet 设置”**。
2. 看到您当前连接的网络（以太网或WiFi），点击 **“属性”**。
3. **一定要选 【专用】 (Private)** ！千万不要选“公用”。
  - *只有选了“专用”，Windows 才会允许手机访问电脑的端口。*

### 🧐 圣旨三：确认电脑的新“龙袍” (IP变了没？)
虽然手机是 `192.168.1.103`，但电脑的 IP 可能跟以前不一样了。
既然换了路由器，**电脑的 IP 99% 变了**。

1. 再次打开电脑的 `cmd`，输入 `ipconfig`。
2. **一定要看现在的 IPv4 地址是多少**。
3. 手机浏览器里输入的地址必须是：`http://[电脑现在的新IP]:8000`
