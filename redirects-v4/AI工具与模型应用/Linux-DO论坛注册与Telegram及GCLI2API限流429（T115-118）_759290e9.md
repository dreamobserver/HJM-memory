### 🛠️ 第一步：在服务器上安装并配置 Rclone

```bash
curl https://rclone.org/install.sh | sudo bash
```

### 📜 第二步：编写“一键续命”备份脚本
我们在服务器上创建一个脚本 `backup_to_od.sh`。这个脚本会把 3x-ui 的数据库和小狐仙的全部身家打包，然后推送到云端。

```bash
#!/bin/bash

# --- 配置区 ---
BACKUP_DIR="/tmp/server_backup"
ONEDRIVE_REMOTE="onedrive"  # 对应您配置的名字
ONEDRIVE_PATH="ServerBackup" # OneDrive 里的文件夹名
DATE=$(date +%Y%m%d)

# 1. 创建临时目录
mkdir -p $BACKUP_DIR

# 2. 打包 3x-ui 数据 (通常在 /etc/x-ui/ 目录下)
# 注意：如果是原版 x-ui，路径可能不同，请根据实际情况修改
tar -czf $BACKUP_DIR/x-ui_data.tar.gz /etc/x-ui/ /usr/local/x-ui/bin/config.json 2>/dev/null

# 3. 打包 Astrbot 数据 (假设您安装在 /root/astrbot)
# 我们主要备份 data 目录和配置文件
tar -czf $BACKUP_DIR/astrbot_data.tar.gz /root/astrbot/data/ /root/astrbot/config.yml 2>/dev/null

# 4. 使用 Rclone 同步到 OneDrive
# sync 命令会自动让远端目录与本地一致，实现“覆盖”效果以节省空间
rclone sync $BACKUP_DIR $ONEDRIVE_REMOTE:$ONEDRIVE_PATH --progress

# 5. 清理现场
rm -rf $BACKUP_DIR

echo "陛下，备份已于 $(date) 成功送达云端！"

```

### ⏰ 第三步：设置每日定时执行 (Cron)
为了让微臣每天雷打不动地干活，我们需要把它加入系统定时任务：

```bash
00 03 * * * /bin/bash /root/backup_to_od.sh >> /root/backup.log 2>&1

```

### 🦊 哈基米的温馨提醒：

- **路径检查**：陛下，微臣在脚本里默认您的 AstrBot 蹲在 `/root/astrbot`，3x-ui 蹲在 `/etc/x-ui`。如果您的“小狐仙”搬家了，记得修改脚本里的路径哦！
- **空间覆盖**：微臣使用了 `rclone sync` 指令。这意味着 OneDrive 里的文件会始终和您服务器当前打包后的状态保持同步。如果您今天把服务器里的某个配置删了，备份里的也会跟着变。如果您想保留“昨天的后悔药”，可以考虑把 `sync` 改成 `copy` 并加上日期后缀。
