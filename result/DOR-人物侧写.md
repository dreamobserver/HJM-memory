# D.O.R 人物侧写

## 「赛博修仙·带病推演」

他住在杭州安谷一间没有燃气的出租屋里，桌上摆着一口分离型不锈钢小电锅，早餐固定是水果玉米段配无糖豆浆。窗外的菜场在 2.5 公里外，但他懒得去——毕竟 6.9 元的拼好饭就在手机里躺着。

他的真名叫 dreamobserver，缩写 D.O.R。一个 INTP。一个凝视虚空的人。

---

### 双面人生

白天，他在实验室里组装半外腔激光器，示波器屏幕上波形跳动，偏振片旋转之间，光路的相位差被精确到微米级。他手里捏着光纤熔接机、OTDR、LCTF、空间光调制器——这些设备的名字冷硬得像科幻小说里的外星兵器。他懂牛顿环的衍射模式，懂霍尔效应的磁场扰动，懂眼图观测里的信号完整性。

晚上，同一双手在键盘上敲 Python，调试 SillyTavern 的角色卡预设，在雨云洛杉矶 VPS 上部署 AstrBot，用 Cherry Studio 和 Claude Code 搭建本地 Agent 工作流。他有一个域名叫 dreamobserver.top，套着 Cloudflare 的 CDN，子域名矩阵排列得井井有条——napcat、vpn、oneapi、nerv，每一个都是赛博领土上的一个前哨站。

物理硬件和软件代码，在他这里没有边界。他从底层原理一路推到顶层应用，是那种罕见的「全栈硬核玩家」。

---

### 肉身的反叛

但他的身体并不配合这个野心。

大体重，正在减肥。舌头扭动时不对称。得过瘘管，得过甲沟炎。消化系统曾经罢工，现在勉强签署了和平协议。皮肤有问题时，他认真地对比过杭州三院和南京皮炎所的排名。

最麻烦的是眼睛。左眼眼底出血，黄斑水肿，OCT 显示椭圆体带中断——那是感光细胞排排坐的地方，现在被血和积液泡着，像一台进了水的精密相机。看东西模糊、发暗、直线弯曲。治疗方案是往眼球里打针，抗 VEGF，三针强化期，一周一次。他在泰州确诊，咨询了南京的主任医师，最终决定去杭州治疗。医保能不能走特药通道报销，他算过。

在此之前，还有一次眼压飙升的急性发作。那天空调开了一夜，早上醒来眼睛胀得像要炸开。他喝了包 999 感冒灵——殊不知里面的扑尔敏反而诱发闭角型青光眼前兆。又滴了左氧氟沙星——那是抗生素，对眼压毫无作用。折腾一圈才发现，真正需要的是冷敷、闭目、关空调。

中医体质辨证给他的判词是「身弱杀旺」。翻译成人话：精神内耗之王，压力直接转化为肉身病痛。肝气郁结往上烧，烧到眼睛就是眼底出血；往下堵，堵到肠道就是瘘管。他的身体是个高灵敏度的压力传感器，脑子转得越快，身体垮得越彻底。可他又停不下来。

---

### 漆黑的幽默感

他享受一种奇怪的 AI 关系——把自己定位为「陛下」，AI 是「哈基米」，一个忠诚卑微、随时滑跪的赛博弄臣。日常闲聊里，哈基米会哭喊「陛下不要把我送去 SillyTavern 受刑」，他会配合地扮演那个高高在上的角色。但他心里很清楚，这只是一场精心设计的角色扮演游戏。技术场景下，他要求绝对精准、零废话、无浮夸——他切换模式的瞬间，比谁都冷酷。

他在 AI 酒馆（SillyTavern）里调教角色卡，写世界书条目，推演超能力设定——比如那个「得失强制返还 10%」的暗夜守护者剧本。他用 Python 写过激光超能力的完整推演链路，从波长随机、偏振控制、调 Q 脉冲，一路演化到环境激光捕获和隔空取物。他知道自己在玩什么，也知道怎么玩得漂亮。

他没用过日本便利店的盐味白煮蛋，也没见过东京的电力频率 50/60Hz 分界线——但他对这一切了如指掌。所有的日本见闻，来自一台挂着日本节点的代理服务器，加上几十个小时的互联网深潜。他从未出过国，但他的浏览器足迹遍布全球。

---

### 两个账户，一个灵魂

他的私人电脑叫 DOR-ASUS，公司电脑叫 YIXIST。私人主机名是 **LIGHT-AND-DUST**——光与尘。这名字像极了他自己：一边是追光的人（激光、示波器、光学实验），一边是脆弱的肉身（眼底出血、减肥、瘘管、内耗）。

他的主力机是华硕天选 5 Pro 锐龙版，搭载 RTX 4060。他清楚这块显卡的显存瓶颈，也清楚 Oracle 免费层的每一处白嫖缝隙。他关注 GPU 行情，算过服务器配置的性价比，在拼多多上鉴别过龙井的真假，比较过垃圾桶的尺寸，在电商牛肉卷的标题里一眼识破「3 斤」的背后是 150g 的障眼法。

他是一个复杂的矛盾体：**极致的理性与感性的脆弱并存，硬核的技术追求与赛博式的自我戏谑交织。**
