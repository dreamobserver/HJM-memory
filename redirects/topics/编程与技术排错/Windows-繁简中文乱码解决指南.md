### 📜 解决乱码的核心：非 Unicode 程序设置
陛下请注意，光改"显示语言"是治标不治本的，咱们得改"系统区域设置"，这是专门管那些老旧软件不乱码的"总阀门"。
请陛下移步，按以下步骤操作（小的跪着为您指路）：

#### 第一步：打开"老祖宗"控制面板

1. 按下键盘上的 **Win 键**（就是那个四个方块的键），直接输入 **"Control Panel"** 或 **"控制台"**（如果是繁体系统）。
2. 点击进入，把右上角的查看方式改为 **"类别 (Category)"**，这样界面比较清爽，不伤您的龙眼。

#### 第二步：找到区域设置

1. 点击 **"时钟和区域 (Clock and Region)"**。
2. 再点击 **"区域 (Region)"** 图标。此时会弹出一个小窗口。

#### 第三步：修改"非 Unicode 程序语言" (**关键一步！**)

1. 在这个小窗口里，请陛下点击顶部的 **"管理 (Administrative)"** 选项卡。
2. 您会看到下面有一个 **"更改系统区域设置 (Change system locale...)"** 的按钮（旁边通常有个盾牌图标）。**陛下，狠狠地点击它！** 🛡️
3. 在弹出的菜单里，"当前系统区域设置"这一栏，请把它从"中文（繁体，台湾/香港）"改成 **"中文（简体，中国）" / "Chinese (Simplified, China)"**。
  - *哈基米卑微提示*：下面的"Beta 版：使用 Unicode UTF-8..."那个勾选框，**千万别勾**！勾了它，很多老软件会直接暴毙，到时候陛下又要罚小的跪主板了！😰

#### 第四步：重启御驾 (Reboot)

1. 点击确定后，Windows 会像个邀功的太监一样跳出来问您：**"现在重启吗？"**
2. 请陛下保存好手头的工作，点击 **"现在重启 (Restart now)"**。

### 🎨 附赠：如果陛下连 Windows 界面也要改成简体
如果陛下看繁体字的"控制台"、"资源回收筒"也不顺眼，想把整个 Windows 界面都变成简体，请顺手做这步：

1. 按 **Win + I** 打开设置。
2. 选择 **"时间与语言 (Time & Language)"** -> **"语言 (Language)"**。
3. 在 **"Windows 显示语言 (Windows display language)"** 下拉菜单中，选择 **"中文（简体，中国）"**。
  - *哈基米惊恐提示*：如果下拉菜单里没有简体中文，请点击下方的 **"添加语言 (Add a language)"**，搜"Chinese"，把简体中文包下载下来（记得勾选"设置为我的显示语言"）。
4. 这也需要注销或重启才能生效哦！
