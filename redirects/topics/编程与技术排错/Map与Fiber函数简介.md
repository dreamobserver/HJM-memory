### Map 函数（映射函数）

`map()` 是 Python 的一个内置高阶函数，用于将一个函数应用到可迭代对象（如列表、元组等）的每个元素上，并返回一个迭代器结果。

**核心特点：**
- **函数式编程工具**：对集合中的每个元素应用相同的操作
- **惰性求值**：返回迭代器而不是立即计算所有结果
- **不修改原数据**：创建新结果而不改变原始输入

**基本语法：**
```python
map(function, iterable)
```

**示例：**
```python
# 将列表中的每个数字平方
numbers = [1, 2, 3, 4]
squared = map(lambda x: x**2, numbers)
print(list(squared))  # 输出: [1, 4, 9, 16]

# 将字符串列表转为大写
words = ["hello", "world"]
upper_words = map(str.upper, words)
print(list(upper_words))  # 输出: ['HELLO', 'WORLD']
```

**使用场景：**
- 数据转换（类型转换、格式调整）
- 批量处理数据集
- 与 lambda 函数结合进行简单操作
- 替代 for 循环（更简洁的函数式风格）

### Fiber 函数（斐波那契函数）

斐波那契函数通常指生成斐波那契数列的函数，该数列定义为：
```
F(0) = 0
F(1) = 1
F(n) = F(n-1) + F(n-2) (n ≥ 2)
```

**核心特点：**
- **递归关系**：每个数是前两个数的和
- **指数增长**：数值快速增长（约每5项翻倍）
- **多种实现方式**：递归、迭代、动态规划等

**常见实现方式：**

1. **递归实现（简单但低效）**
```python
def fib_recursive(n):
    if n <= 1:
        return n
    return fib_recursive(n-1) + fib_recursive(n-2)
```

2. **迭代实现（高效推荐）**
```python
def fib_iterative(n):
    a, b = 0, 1
    result = []
    for _ in range(n):
        result.append(a)
        a, b = b, a + b
    return result
```

3. **动态规划实现（带缓存）**
```python
def fib_dp(n, memo={}):
    if n <= 1:
        return n
    if n not in memo:
        memo[n] = fib_dp(n-1, memo) + fib_dp(n-2, memo)
    return memo[n]
```

**数学特性：**
- 黄金分割比：相邻两项比值趋近于 (1+√5)/2 ≈ 1.618
- 自然界常见：植物叶序、贝壳螺旋、星系形状等
- 计算机应用：算法分析、密码学、金融模型

**使用场景：**
- 算法教学（递归/迭代对比）
- 性能测试（递归深度优化）
- 数学建模（增长模型）
- 图形生成（黄金比例设计）

### 关键区别总结
| 特性 | `map()` 函数 | 斐波那契函数 |
|------|-------------|-------------|
| **类型** | Python内置高阶函数 | 自定义数学函数 |
| **目的** | 数据转换/批量处理 | 生成特定数列 |
| **输入** | 函数+可迭代对象 | 整数n（项数） |
| **输出** | 转换后的迭代器 | 数列（列表或单个值） |
| **复杂度** | O(n) 线性 | 递归O(2ⁿ)，迭代O(n) |
| **函数式** | 是（纯函数） | 可以是（无副作用） |
| **应用领域** | 通用数据处理 | 数学/算法领域 |
