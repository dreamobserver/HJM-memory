# POTPLAYER如何显示视频的对比度，亮度，锐度等参数

**分类**：编程与技术排错
**来源**：DeepSeek Chat 导出
**来源平台**：DeepSeek
**原始文件**：光纤标尺标定失败解决方案.md
**包含轮次**：3 - 3

---

# 用户：
POTPLAYER如何显示视频的对比度，亮度，锐度等参数

# DeepSeek：

**原始回答**
在 PotPlayer 中查看和调整视频的对比度、亮度、锐度等参数，需要通过内置的**视频滤镜控制面板**实现。以下是详细操作指南：

---

### **方法一：通过快捷键直接调整（实时显示参数值）**
1. **打开视频**：播放任意视频文件。
2. **启用参数调整**：
   - **亮度**：按 `Ctrl + Alt + B`  
     *屏幕左上角会显示当前亮度值（如：`Brightness: 15`）*
   - **对比度**：按 `Ctrl + Alt + C`  
     *显示示例：`Contrast: 10`*
   - **锐度**：按 `Ctrl + Alt + S`  
     *显示示例：`Sharpness: 20`*
3. **调整参数**：  
   按快捷键后：
   - **↑/↓ 方向键**：增减数值（步进±1）
   - **Enter 键**：确认修改
   - **Esc 键**：取消修改

> 📌 **提示**：数值范围通常为 **-100 到 +100**，0 表示默认值。

---

### **方法二：通过控制面板查看/调整（完整参数界面）**
1. **打开控制面板**：
   - 右键点击播放画面 → 选择 **"视频"** → **"视频效果调整"**
   - 或直接按快捷键 **`Ctrl + F5`**
2. **查看和修改参数**：  
   在弹出的窗口中可调整：
   | **参数**      | **功能**                          | **推荐范围** |
   |---------------|----------------------------------|-------------|
   | 亮度 (Brightness) | 整体明暗程度                     | -10 ~ +10   |
   | 对比度 (Contrast) | 最亮与最暗部分的差异             | 0 ~ +20     |
   | 饱和度 (Saturation) | 颜色鲜艳程度                    | -10 ~ +30   |
   | 色相 (Hue)      | 整体颜色偏移                     | 通常保持 0  |
   | 伽马值 (Gamma)  | 中间调明暗                      | 0.8 ~ 1.2   |
   | **锐度 (Sharpness)** | 边缘清晰度（关键参数）       | 0 ~ +30     |
3. **实时显示**：  
   调整滑块时，右侧数字框会**实时显示当前数值**（例如：`Sharpness: 25`）。

---

### **方法三：启用OSD信息显示（高级）**
1. **开启OSD**：
   - 按 `Tab` 键 → 屏幕显示**视频编码信息**（分辨率/帧率等）
   - *但默认不包含画质参数*
2. **自定义显示参数**（需修改设置）：
   - 右键 → **"偏好设置"** (F5) → **"播放"** → **"信息/其他设置"**
   - 在 **"OSD（屏幕显示）"** 选项卡中：
     1. 勾选 **"显示播放信息"**
     2. 在 **"信息行内容"** 添加代码：  
        ```
        [亮度]%brightness% [对比度]%contrast% [锐度]%sharpness%
        ```
   - 保存后播放视频时，按 `Tab` 将显示类似：  
     `亮度:5 对比度:10 锐度:20`

---

### **解决您标定尺摩尔纹的专用设置**
针对标定尺优化画质：
1. 打开 `Ctrl + F5` 视频效果面板
2. 按如下调整：
   - **锐度 (Sharpness)**：降至 **-10**（减少摩尔纹伪影）
   - **对比度 (Contrast)**：增至 **+15**（强化刻度线边缘）
   - **伽马值 (Gamma)**：设为 **1.1**（提升中间调可见性）
3. 点击 **"保存为预设"** → 命名如 `标定模式`

---

### **注意事项**
1. 所有调整仅影响**软件渲染效果**，不会修改原始视频文件。
2. 参数重置方法：  
   - 在视频效果面板点击 **"重置"**
   - 或删除安装目录下的 `PotPlayer.ini` 配置文件。
3. 对采集卡画面：建议在 **"视频渲染器"** 中选用 **"EVR(CP)"** 模式（右键→视频→视频渲染器）。

> 💡 **专业技巧**：在标定过程中，建议将锐度设为 **-15** 并固定亮度/对比度，可显著减少彩色摩尔纹干扰。
