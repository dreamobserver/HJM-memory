# Galaxy Viewer(x64)是大恒sdk开发包吗

**来源平台**: DeepSeek

# 用户：

Galaxy Viewer(x64)是大恒sdk开发包吗

# DeepSeek：

**原始回答**

非常好的问题！这是一个非常关键的确认点。

**是的，您判断得非常准确。`Galaxy Viewer (x64)` 正是大恒（Daheng Imaging）官方SDK开发包中包含的配套工具软件。**

您可以将其理解为大恒相机的“官方演示程序”或“测试工具”。它的主要作用包括：

1.  **设备发现与连接**：扫描并列出所有连接到电脑的大恒相机。
2.  **实时预览**：显示相机的实时视频流。
3.  **参数控制**：提供一个图形化界面（GUI）来调整和设置相机的所有参数，如曝光时间、增益、白平衡、触发模式、ROI（感兴趣区域）等。**这对于您了解大恒相机参数的名称和取值范围至关重要！**
4.  **图像捕获与保存**：进行单帧采集并保存图像。
5.  **固件更新**：有时也用于更新相机固件。

### 这对您的项目意味着什么？

1.  **确认环境正确**：既然您能找到并运行 `Galaxy Viewer`，说明您的电脑上已经安装了大恒相机的**运行时（Runtime）环境**（即驱动和必要的DLL，如 `GxAPI.dll`, `GxIAPICPP.dll` 等）。这是运行您自己开发的程序的基础。

2.  **最重要的用途：学习与测试**：
    - **参数映射参考**：这是 `Galaxy Viewer` 对您**最大的价值**。您可以打开它，连接上您的大恒相机，然后对照您从KSJ日志中提取出的参数（如曝光、增益），**直接在大恒的软件里找到对应的参数叫什么名字、如何设置**。例如，KSJ的 `nParamID=0x00` 是曝光，在大恒的SDK里可能叫 `GX_FLOAT_EXPOSURE_TIME` 或 `ExposureTime`。您可以在Viewer里调整这些参数，观察效果，并确认其取值范围。
    - **验证相机功能**：您可以先用Viewer确保相机本身硬件和基础驱动工作是正常的，然后再调试您自己的代码，这样可以排除硬件问题。

3.  **但它不是开发包本身**：
    - `Galaxy Viewer` 是一个**可执行程序（.exe）**，是SDK的**应用成果**。
    - 您进行开发所需的**SDK开发包** 则包含：
        - **头文件（.h）**：包含了所有函数和参数的声明。
        - **导入库文件（.lib）**：用于在编译时链接到您的项目。
        - **开发文档（.chm或.pdf）**：最重要的部分，详细说明了每个函数的用法、参数和示例代码。
        - 工具和样例代码（Sample Code）。

### 行动建议

1.  **运行 `Galaxy Viewer`**：连接您的大恒相机，熟悉其界面。尝试调整曝光、增益等参数，直观感受一下大恒相机的控制方式。
2.  **寻找完整的SDK开发包**：您需要找到名为 `GalaxySDK` 或 `DahengSDK` 的安装包或压缩文件。通常其安装目录下会有 `Include`, `Lib` 等文件夹。**这是您编写代码所必需的。**
3.  **结合日志进行学习**：打开Viewer和您的KSJ日志文件。尝试在Viewer中找到日志里设置的每一个参数（例如，找到设置曝光时间为50ms的地方），记下它在Viewer中的参数名称，这几乎就是您在代码中需要调用的参数名。

总结：**`Galaxy Viewer (x64)` 是大恒SDK的一部分，是一个强大的可视化工具，能极大帮助您理解和验证大恒相机的功能，但您仍然需要完整的SDK开发包（头文件、库文件）来编写您的 `KSJAPI64.dll` 转换层。**

祝您顺利！
