### **1. 代码生成示例**  
#### **需求：用 Python 写一个快速排序（Quick Sort）算法**  
```python
def quick_sort(arr):
    if len(arr) <= 1:
        return arr
    pivot = arr[len(arr) // 2]
    left = [x for x in arr if x < pivot]
    middle = [x for x in arr if x == pivot]
    right = [x for x in arr if x > pivot]
    return quick_sort(left) + middle + quick_sort(right)

# 测试
array = [3, 6, 8, 10, 1, 2, 1]
print("排序前:", array)
print("排序后:", quick_sort(array))
```
**输出：**  
```
排序前: [3, 6, 8, 10, 1, 2, 1]  
排序后: [1, 1, 2, 3, 6, 8, 10]
```

### **2. 代码调试示例**  
#### **需求：以下 Python 代码报错，请修复**  
```python
def divide(a, b):
    return a / b

result = divide(10, 0)
print(result)
```
**问题：** 当 `b=0` 时，会抛出 `ZeroDivisionError`。  
**修复后代码：**  
```python
def divide(a, b):
    try:
        return a / b
    except ZeroDivisionError:
        return "除数不能为零！"

result = divide(10, 0)
print(result)  # 输出: "除数不能为零！"
```

### **3. 复杂任务：爬取网页数据（使用 `requests` 和 `BeautifulSoup`）**  
#### **需求：爬取某个网页的标题和所有链接**  
```python
import requests
from bs4 import BeautifulSoup

def scrape_website(url):
    try:
        response = requests.get(url)
        response.raise_for_status()  # 检查请求是否成功
        soup = BeautifulSoup(response.text, 'html.parser')
        
        print("网页标题:", soup.title.string)
        print("\n所有链接：")
        for link in soup.find_all('a', href=True):
            print(link['href'])
    except Exception as e:
        print("爬取失败:", e)

# 示例：爬取 DeepSeek 官网（假设网址）
scrape_website("https://www.deepseek.com")
```

### **4. 算法优化示例**  
#### **需求：优化斐波那契数列计算（避免递归重复计算）**  
**原始递归版本（低效）：**  
```python
def fib(n):
    if n <= 1:
        return n
    return fib(n-1) + fib(n-2)
```
**优化版本（动态规划）：**  
```python
def fib(n, memo={}):
    if n in memo:
        return memo[n]
    if n <= 1:
        return n
    memo[n] = fib(n-1, memo) + fib(n-2, memo)
    return memo[n]

print(fib(50))  # 快速计算第50项
```
