### Gemini CLI 的停服细节

- **强制一刀切：** 到了 2026年6月18日，针对免费层、Google AI Pro 以及 Ultra 用户的 Gemini CLI 服务将被直接切断，没有任何宽限期，强行调用只会返回报错。
- **新工具接棒：** Google 推出了全新的 **Antigravity CLI**（终端命令从 `gemini` 变更为 `agy`）作为替代方案。新工具使用 Go 语言全面重写，旨在更好地支持多智能体（Agent）并发和异步工作流。
- **企业用户的特权：** 如果使用的是企业级 Gemini Code Assist Standard 或 Enterprise 许可证，目前的访问权限将不受该日期的影响。

### Google Cloud CLI (`gcloud`)

如果你指的是日常用来管理云端基础设施的 **Google Cloud CLI (gcloud)**，那完全不用担心，它作为核心工具**并没有"死期"**，目前依然在稳定运营。
不过，`gcloud` 生态内的某些特定老旧插件已经完成了它们的历史使命并被彻底关停：

- **Cloud Tools for PowerShell：** 已于 2026年2月16日 正式关闭服务。
- **Cloud Tools for Visual Studio：** 已于 2026年4月2日 正式关闭服务。
