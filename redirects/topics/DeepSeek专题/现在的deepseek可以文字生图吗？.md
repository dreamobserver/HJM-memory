# 现在的deepseek可以文字生图吗？

**分类**: DeepSeek专题
**来源**: DeepSeek Chat 导出
**来源平台**: DeepSeek

---

# 用户：

现在的deepseek可以文字生图吗？

# DeepSeek：

**原始回答**

是的，DeepSeek 目前已经具备文字生成图像（文生图）的能力，但具体实现方式分以下两种情况：

---

### ✅ 一、**通过独立的多模态模型 Janus-Pro（原生支持文生图）**
2025年1月28日，DeepSeek 发布了 **Janus-Pro 多模态模型**，专门支持文字生成图像（文生图），有 7B（70亿参数）和 1.5B（15亿参数）两个版本，均已开源。

- **效果如何？**  
  在多项测试中表现优异，甚至**超过 OpenAI DALL-E 3**：
  - GenEval 测试准确率 **80%**（DALL-E 3 为 67%）
  - DPG-Bench 得分 **84.2%**（超过所有对比模型）
- **特点：**
  - 支持“读图”（识别图像内容）和“生图”（根据文字生成图像）
  - 在 Hugging Face 上提供免费试用：
    👉 [Janus-Pro 7B 试用地址](https://huggingface.co/spaces/deepseek-ai/Janus-Pro-7B)

> 💡 总结：**Janus-Pro 是 DeepSeek 真正的文生图模型**，效果强大、专业开源，但目前**尚未集成到 DeepSeek R1（你正在使用的聊天助手）中**。

---

### ⚠️ 二、**在 DeepSeek R1 中实现“文生图”（间接方法）**
你现在使用的 **DeepSeek R1（纯文本推理模型）本身不支持图像生成**，但可以通过“曲线救国”的方式实现类似效果：

#### 🔧 方法：利用第三方 API + Markdown 图片渲染
向 DeepSeek R1 发送如下指令：

```
你现在是一个AI图片生成机器人。用英文描述我要求的画面，填充到下面这个链接的 {prompt} 位置，然后直接返回 Markdown 格式的图片链接：
![image](https://image.pollinations.ai/prompt/{prompt}?width=1024&height=1024&model=flux)
```

例如你输入：
> 画一只中国传统龙在云中翻腾，龙身缠绕着“ABAP”字母

DeepSeek R1 会返回一个渲染好的图片链接，点击即可查看生成的图像。

#### ⚖️ 效果评估：
- ✅ 优点：免费、简单、无需切换工具  
- ❌ 缺点：依赖第三方服务（Pollinations AI），图像质量不稳定，不如 Janus-Pro 专业

---

### 🚀 总结建议：
| 能力                | 支持情况                     | 推荐度 |
|---------------------|-----------------------------|--------|
| **DeepSeek R1（你正在用的）** | ❌ 不支持原生文生图<br>✅ 可间接实现（质量一般） | ⭐⭐    |
| **Janus-Pro 多模态模型**     | ✅ 原生文生图，效果顶尖           | ⭐⭐⭐⭐  |
| **集成进度**         | Janus-Pro 暂未接入 R1，需独立使用 | 待更新 |
