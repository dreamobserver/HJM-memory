### ⚙️ **一、实验系统设计（简化版）**  
#### **1. 光路模块**（解决核心创新：**赝热光生成+强度探测**）  
| **组件**          | **教学级替代方案**          | **原技术对应**               |  
|-------------------|---------------------------|-----------------------------|  
| **光源**          | 激光器+旋转毛玻璃          | 8激光器+大气湍流调制         |  
| **目标物**        | 透射式分辨率板（毫米级特征）| 1.36km外反射目标            |  
| **探测端**        | 双路CMOS相机（非单光子）   | 可移动望远镜+单光子探测器    |  
| **关联基线**      | 导轨平移相机（0.1-0.5m可调）| 0.07-0.87m基线              |  

**光路创新点复现**：  
- **赝热光模拟**：激光经高速旋转毛玻璃产生动态散斑（模拟湍流调制效果），替代复杂大气传输  
- **双路同步采集**：两台相机通过触发信号同步曝光，测量空间两点的光强波动 \(I_1(t)\), \(I_2(t)\)  

#### **2. 算法模块**（解决核心创新：**关联函数计算+图像重建**）  
```python
# 学生需完成的代码核心步骤（Python示例）
# 1. 计算二阶强度关联函数
g2 = np.zeros((num_baselines))  # 存储不同基线的关联值
for k in range(num_baselines):
    I1 = data[k][:, 0]  # 位置1的光强序列
    I2 = data[k][:, 1]  # 位置2的光强序列
    g2[k] = np.mean(I1 * I2) / (np.mean(I1) * np.mean(I2)) - 1  # g²(τ=0)

# 2. 从关联值重建图像（傅里叶变换法）
# 关联值g2(k) ↔ 空间频谱V(u,v) 
u = baseline_x / wavelength  # 空间频率坐标
v = baseline_y / wavelength
spectrum = g2_to_spectrum(g2)  # 根据基线映射关系转换

# 3. 逆傅里叶变换重建图像
image = np.abs(np.fft.ifft2(spectrum))
```

### 📝 **二、实验内容分层设计**  
#### **基础任务（3课时）**  
1. **光路搭建与标定**  
   - 调试旋转毛玻璃转速，用CCD观察散斑场变化（验证赝热光特性）  
   - 测量不同基线长度下的关联值衰减曲线（验证Hanbury Brown-Twiss效应）  

2. **关联成像体验**  
   - 对单孔/双孔目标采集数据，计算g²值并重建图像  
   - 对比直接成像 vs 关联成像的分辨率差异（示例：0.5mm孔径在2m距离）  

#### **进阶任务（3课时拓展）**  
1. **抗干扰能力验证**  
   - 在光路中加入扰动（如风扇模拟湍流），对比传统干涉仪与强度干涉的图像退化程度  
2. **算法优化挑战**  
   - 用**压缩感知算法**改进稀疏基线重建（提供MATLAB/Python模板）  
   - 尝试重建复杂目标（如“光”字镂空板）
