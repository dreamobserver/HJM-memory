# epson l4260是激光打印机吗

**分类**: 光学与物理实验
**来源**: DeepSeek Chat 导出
**来源平台**: DeepSeek

---

# 用户：

epson l4260是激光打印机吗

# DeepSeek：

**原始回答**

不是，**爱普生（Epson）L4260** 是一款**墨仓式（EcoTank）喷墨打印机**，而不是激光打印机。  

### 主要特点：  
1. **使用墨水**：采用爱普生特有的微压电喷墨技术，使用瓶装墨水（非激光打印机用的碳粉）。  
2. **墨仓式设计**：内置大容量墨水仓，打印成本较低，适合家庭或小型办公高频打印需求。  
3. **功能**：支持打印、复印、扫描（三合一），无线连接（Wi-Fi）。  

如果你需要激光打印机，可以考虑爱普生的 **激光系列（如 Epson M 或 Epson B 系列）**，或者惠普（HP）、兄弟（Brother）等品牌的激光机型。
