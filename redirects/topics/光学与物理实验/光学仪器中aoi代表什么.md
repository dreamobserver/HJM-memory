# 用户：

# DeepSeek：

**原始回答**

在光学仪器（尤其是工业检测和电子制造领域）中，**AOI** 通常代表 **Automated Optical Inspection（自动光学检测）**。

简单来说，它是一种利用**机器视觉**（相机+光源+算法）来检测产品缺陷的技术。常见应用场景包括：

- **PCB / SMT 领域**：检测电路板上元件是否漏贴、错位、极性反，或检查焊点质量（如虚焊、连锡）。
- **显示面板制造**：查找屏幕上的亮点、暗点、划痕或 Mura（亮度不均）。
- **其它精密零件**：检测五金件尺寸、表面划伤、异物等。

核心流程：相机采集图像 → 软件分析对比 → 判断良品/缺陷 → 输出结果。

**与之前讨论的 OTDR（光时域反射计）不同**，AOI 主要用于**表面外观和装配质量检测**，不测量光纤的长度、损耗或断点。

如果你是在某个具体设备的说明书或参数表里看到这个词，可以发一下上下文，我帮你确认是否为此含义。
