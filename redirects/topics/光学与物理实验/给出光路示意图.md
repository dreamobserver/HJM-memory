### 🔍 **核心模块详解**
#### **1. 赝热光源生成模块**（创新核心）
```plaintext
激光器 → 分束镜(BS) → 旋转毛玻璃 → 动态散斑场
```
- **作用**：将相干激光转化为相位随机的赝热光  
- **教学替代方案**：  
  - 用**高速旋转毛玻璃**（2000-5000 RPM）替代大气湍流调制  
  - 毛玻璃表面粗糙度使激光波前随机畸变，产生动态散斑（模拟热光场）  

#### **2. 双路关联探测模块**
```plaintext
动态散斑场 → 扩束器 → 目标物 → 双透镜成像 → 双CMOS相机
```
- **基线调节**：相机2安装在**电动平移导轨**上，基线距d可调（0.1–0.5m）  
- **同步触发**：两相机通过外部TTL信号同步曝光（μs级精度）  

#### **3. 信号处理模块**
```plaintext
相机采集(I1,I2) → 计算机计算g²函数 → 图像重建
```
- **关联计算**：  
  \( g^{(2)}(d) = \frac{\langle I_1(t) I_2(t) \rangle}{\langle I_1(t) \rangle \langle I_2(t) \rangle} - 1 \)  
- **分辨率验证**：通过改变d，观察双缝目标重建图像的分辨率变化

```python
def calculate_g2(frame1, frame2):  # 输入双相机单帧数据
    I1 = frame1.astype(float)
    I2 = frame2.astype(float)
    g2 = np.mean(I1 * I2) / (np.mean(I1) * np.mean(I2)) - 1
    return g2

def reconstruct_image(g2_values, baselines):
    # 将g2映射到空间频谱 (u = baseline / λ)
    spectrum = np.zeros((512, 512), dtype=complex)
    for i, d in enumerate(baselines):
        u = d / 632e-9  # He-Ne激光波长
        spectrum[int(u), 0] = g2_values[i]  # 简化一维重建
    image = np.abs(np.fft.ifft2(spectrum))
    return image
```
