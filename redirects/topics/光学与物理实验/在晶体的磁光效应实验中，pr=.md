   - 加入第一个PBS后最大功率为`1.11mW`：调整偏振态后通过PBS的最大功率。
   - `pf=6.04μW`：经过隔离器后的泄漏功率。

2. **隔离度计算**：
   - 隔离度定义为输入反向功率与输出反向功率的比值取对数后的分贝值。
   - 输入到隔离器的反向功率为经过PBS后的`1.11mW`，输出功率为`6.04μW`。
   - 单位统一：`1.11mW = 1110μW`，`6.04μW`保持不变。
   - 计算比值：`1110 / 6.04 ≈ 183.77`。
   - 取对数：`log10(183.77) ≈ 2.264`。
   - 隔离度：`10 * 2.264 ≈ 22.64dB`，四舍五入约为`23dB`。

3. **合理性判断**：
   - 一般光学隔离器的隔离度在20dB到40dB之间，23dB属于合理范围，但中等偏低。适用于一般实验场景，若需高隔离度则可能不足。
