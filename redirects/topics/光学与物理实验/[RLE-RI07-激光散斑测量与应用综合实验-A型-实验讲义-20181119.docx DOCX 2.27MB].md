### ⚙️**二、光路改装方案**

在**原系统光路基础上调整**（参考实验一装配图）：

````plaintext
原系统光路：  
激光器 → 分光光楔 → 物光扩束 → 物体 → NPBS → 相机  
                      ↑  
          参考光 → 扩束 → 毛玻璃 → NPBS  

改装后光路：  
激光器 → 分束镜(BS) → 旋转毛玻璃（赝热光）→ 扩束 → 目标物 → 双透镜 → 双CMOS相机  
                                   (移除参考光路，新增双探测通道)
````

#### **具体调整步骤**：

1. **移除冗余模块**：
    - 拆除分光光楔、参考光扩束镜、衰减器
    - 保留**旋转毛玻璃**（置于激光器后模拟湍流）
1. **新增关键部件**：
    - 增加**50:50分束镜(BS)**：将赝热光分为两路（物光照明）
    - 增加**第二台CMOS相机**：与原相机并列安装于平移导轨上（基线距0.1–0.5m可调）
    - 增加**同步触发模块**：确保双相机曝光时间同步（μs级精度，可用Arduino开发板实现）
1. **光路重组**：
````plaintext
激光器 → 旋转毛玻璃 → 分束镜(BS) 
                    ├─ 光束1 → 扩束镜1 → 目标物 → 透镜1 → 相机1  
                    └─ 光束2 → 扩束镜2 → 目标物 → 透镜2 → 相机2  
````
    - **目标物**：改用透射式分辨率板（原系统反射物不适用）
    - **基线调节**：相机2固定于电动平移台（复用原系统位移平台）

### 💻**三、算法与软件改装**

**保留原软件框架，替换核心计算模块**：

#### **代码示例（集成到原软件）**：

````python
# 在原采集软件中新增按钮"关联成像"
def calculate_g2(frame1, frame2):  # 输入双相机单帧数据
    I1 = frame1.astype(float)
    I2 = frame2.astype(float)
    g2 = np.mean(I1 * I2) / (np.mean(I1) * np.mean(I2)) - 1
    return g2

def reconstruct_image(g2_values, baselines):
    # 将g2映射到空间频谱 (u = baseline / λ)
    spectrum = np.zeros((512, 512), dtype=complex)
    for i, d in enumerate(baselines):
        u = d / 632e-9  # He-Ne激光波长
        spectrum[int(u), 0] = g2_values[i]  # 简化一维重建
    image = np.abs(np.fft.ifft2(spectrum))
    return image
````
