# 激光在22.2ns移动距离

# 用户：

激光在22.2ns移动距离

# DeepSeek：

**原始回答**

激光是电磁波，在真空中以光速传播，光速 \( c = 3 \times 10^8 \, \text{m/s} \)。  
给定时间 \( t = 22.2 \, \text{ns} = 22.2 \times 10^{-9} \, \text{s} = 2.22 \times 10^{-8} \, \text{s} \)。  
移动距离的计算公式为：  
\[ \text{距离} = c \times t \]  
代入数值：  
\[ \text{距离} = (3 \times 10^8 \, \text{m/s}) \times (2.22 \times 10^{-8} \, \text{s}) = 6.66 \, \text{m} \]  
因此，激光在 22.2 纳秒内移动的距离为 **6.66 米**。
