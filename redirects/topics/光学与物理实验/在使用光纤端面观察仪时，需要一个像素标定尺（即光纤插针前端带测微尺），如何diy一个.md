# DIY光纤端面观察仪像素标定尺

要DIY一个用于光纤端面观察仪的像素标定尺（带测微尺的光纤插针），可以按照以下步骤进行：

## 所需材料
- 标准光纤插针（FC/PC或SC类型，取决于您的连接器类型）
- 精密测微尺（可从显微镜配件或电子显微镜标定片获得）
- 环氧树脂胶或UV固化胶
- 细镊子
- 显微镜或放大镜
- 清洁用品（异丙醇、无尘布）

## 制作步骤

1. **选择测微尺**：
   - 获取一个小型精密测微尺，理想尺寸是1-2mm范围，最小刻度1-10μm
   - 可以从旧显微镜配件、电子显微镜标定片或在线购买微型测微尺

2. **准备光纤插针**：
   - 彻底清洁光纤插针端面
   - 确保端面无划痕、无污染

3. **固定测微尺**：
   - 使用细镊子将测微尺小心放置在插针端面边缘
   - 确保测微尺的刻度清晰可见且不遮挡中心观察区域
   - 使用微量环氧树脂或UV胶固定
   - 固化时确保测微尺位置不变

4. **质量控制**：
   - 检查测微尺是否牢固固定
   - 确保刻度清晰可见
   - 检查是否有胶水污染刻度区域

## 替代方案

如果没有专业测微尺，可以使用：
1. **自制刻度**：
   - 在透明胶片上用激光打印机打印精细刻度（精度较低）
   - 使用电子束光刻技术制作更精细的刻度

2. **使用已知尺寸的物体**：
   - 某些电子元件有标准尺寸特征可作为参考

## 使用注意事项
- 标定时确保观察仪聚焦准确
- 定期检查标定尺的准确性
- 避免划伤或污染标定尺表面

## 专业建议

如需高精度标定，建议购买专业的光纤端面检测仪标定配件，DIY方法可能无法达到实验室级精度要求。

# 使用激光打标和透明亚克力自制10μm分度测微尺的可行性分析

确实可以尝试用激光打标机和透明亚克力手工制作10μm分度的测微尺，但需要考虑以下几个关键因素：

## 可行性评估

### 优势
- **材料易得**：透明亚克力板容易获取且成本低
- **加工便捷**：激光打标机可以直接在表面刻线
- **DIY友好**：适合实验室自制需求

### 挑战
1. **激光打标精度限制**：
   - 普通激光打标机最小线宽通常为20-50μm
   - 高精度工业级激光才能达到10μm以下线宽
   - 刻线边缘可能存在热影响区，影响测量精度

2. **材料限制**：
   - 亚克力表面硬度较低(约M80-100)，易划伤
   - 长期使用后刻线可能模糊

3. **装配难度**：
   - 需要精确对准光纤端面中心
   - 固定时需避免引入倾斜误差

## 改进方案

### 如果仍想尝试制作：

1. **材料升级**：
   - 改用光学级石英玻璃(硬度更高，热膨胀系数更低)
   - 或使用镀铬玻璃基板(刻线对比度更好)

2. **加工优化**：
   - 使用405nm紫外激光器(热影响更小)
   - 采用多次浅刻工艺减少熔边效应
   - 设计补偿图案(如刻线端部加粗)

3. **结构设计**：
   ```plaintext
   [光纤插针端面示意图]
   ┌──────────────────────┐
   │  ● 光纤核心          │
   │  ┌───────┐           │
   │  │ 刻度区│←激光刻线  │
   │  └───────┘           │
   └──────────────────────┘
   ```

4. **校准验证**：
   - 使用已知精度的显微镜标定片进行比对校准
   - 通过图像分析软件验证刻度准确性

# 购买微型光栅片作为测微尺的关键参数指南

如果您决定购买微型光栅片作为光纤端面观察仪的测微尺，以下是需要重点关注的参数规格：

## 核心参数要求

1. **光栅周期（关键参数）**：
   - 您需要的10μm分度值对应 **100线/mm**的光栅
   - 参数表示：100 lines/mm 或 10μm period

2. **物理尺寸**：
   - 直径/边长：建议1.5-3mm（适配光纤插针端面）
   - 厚度：推荐0.1-0.5mm（太厚影响观察）

3. **基底材料**：
   - 优选：紫外级熔融石英（热稳定性好）
   - 替代：光学玻璃（BK7等）

4. **刻线类型**：
   - 振幅型（振幅光栅）：黑白对比明显
   - 相位型（相位光栅）：更高衍射效率

## 其他重要参数

5. **工作波长**：
   - 匹配您的观察仪光源（通常可见光波段400-700nm）

6. **镀膜要求**：
   - 无镀膜：适用于透射式观察
   - 铝/铬镀膜：增强反射式观察对比度

7. **刻线方向**：
   - 单向光栅即可（不需交叉光栅）

8. **安装方式**：
   - 裸片（需自行粘接）
   - 预封装（带金属环等固定结构）
