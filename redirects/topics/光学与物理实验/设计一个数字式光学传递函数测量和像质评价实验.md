### **实验名称**  
数字式光学传递函数（OTF）测量与光学系统像质评价

---

### **一、实验目的**
1. 理解光学传递函数（OTF）的物理意义（包含MTF调制传递函数和PTF相位传递函数）。
2. 掌握基于数字图像处理的斜边法（Slanted-Edge Method）测量MTF的原理。
3. 搭建光学实验平台，采集刃边图像并计算待测镜头的MTF曲线。
4. 通过MTF曲线评价镜头成像质量（分辨率、对比度衰减）。

---

### **二、实验原理**
#### **核心理论**
- **光学传递函数（OTF）**：描述光学系统对空间频率的传递能力，是点扩散函数（PSF）的傅里叶变换：
  $$
  \text{OTF}(f_x, f_y) = \mathcal{F}\{\text{PSF}(x,y)\}
  $$
- **MTF**：OTF的模值，反映系统对各空间频率的**对比度传递能力**。
- **斜边法原理**：
  1. 拍摄一条**倾斜的高对比度刃边**（如刀口或分辨率板斜边）。
  2. 提取刃边区域的灰度分布，得到**边缘扩散函数（ESF）**。
  3. 对ESF求导得到**线扩散函数（LSF）**。
  4. 对LSF进行傅里叶变换并归一化，得到**MTF曲线**。

### **四、实验步骤**
#### **(1) 系统搭建与校准**
1. 将光源、分辨率板、待测镜头、相机共轴排列。

#### **(2) 图像采集**
1. 设置相机参数：曝光时间（避免过曝）、ISO（最低）、RAW格式保存。
2. 拍摄斜边靶标图像（确保斜边倾斜角度5°~10°）。
3. 存储图像：`lens_test_50mm_f2.8.tiff`。

#### **(3) 数据处理（Python示例）**
```python
import numpy as np
import matplotlib.pyplot as plt
from scipy.fft import fft, fftshift
from skimage import io, filters

# 1. 读取图像并提取ROI（刃边区域）
image = io.imread('lens_test_50mm_f2.8.tiff', as_gray=True)
roi = image[300:500, 400:600]  # 选择包含斜边的区域

# 2. 边缘检测与亚像素定位
edge_coords = filters.sobel(roi)  # Sobel算子检测边缘
angle = np.arctan2(np.gradient(edge_coords)[1], np.gradient(edge_coords)[0])  # 计算边缘角度

# 3. 投影生成ESF（边缘扩散函数）
esf = [] 
for i in range(roi.shape[0]):
    esf.append(np.mean(roi[i, :]))  # 沿边缘法线方向投影

# 4. 微分得到LSF（线扩散函数）
lsf = np.gradient(esf)  

# 5. 傅里叶变换计算MTF
mtf = np.abs(fftshift(fft(lsf)))
mtf /= mtf.max()  # 归一化
freq = np.linspace(-0.5, 0.5, len(mtf)) * (1 / (2 * pixel_size))  # 空间频率（lp/mm）

# 6. 绘制MTF曲线
plt.plot(freq[freq>0], mtf[len(mtf)//2:])  # 仅显示正频率部分
plt.xlabel('Spatial Frequency (lp/mm)')
plt.ylabel('MTF')
plt.title('MTF of 50mm f/2.8 Lens')
plt.grid(True)
plt.show()
```

## 三、实验原理
### 核心理论：
- **光学传递函数 (OTF)** = 系统对正弦光栅的响应 = **MTF（调制传递）** × *e*<sup>−i·PTF（相位传递）</sup>
- **MTF**：描述系统对比度传递能力（0 ≤ MTF ≤ 1），空间频率↑ → MTF↓  
- **PTF**：描述系统引起的相位偏移（影响像的位置）

### 测量方法（斜边法）：
1. **采集刀口（或斜边）像**：使用高对比度刀口靶标成像；
2. **提取边缘扩散函数（ESF）**：从刀口像中提取灰度过渡曲线；
3. **微分得线扩散函数（LSF）**：ESF的导数即为LSF；
4. **傅里叶变换得MTF**：对LSF进行FFT → 取模归一化 → MTF曲线。

- 采集**刀口边缘像**（边缘与像元行/列成约2°~5°角避免混叠）；

### 3. 数据处理流程（以Python为例）
```python
import numpy as np
import matplotlib.pyplot as plt
from scipy.fft import fft, fftfreq

# 步骤1：读取刀口图像 → 提取ROI（Region of Interest）
image = plt.imread('knife_edge.tif')
roi = image[100:300, 150:250]  # 选择边缘清晰区域

# 步骤2：投影叠加生成ESF（Edge Spread Function）
esf = np.mean(roi, axis=0)     # 沿边缘垂直方向平均

# 步骤3：数值微分得LSF（Line Spread Function）
lsf = np.gradient(esf)         # 一阶导数近似LSF

# 步骤4：FFT计算MTF
n = len(lsf)
freq = fftfreq(n, d=pixel_size)  # pixel_size=相机像元尺寸（μm）
mtf = np.abs(fft(lsf))          # 取FFT模值
mtf = mtf / mtf.max()           # 归一化
mtf = mtf[:n//2]                # 取正频率部分

# 步骤5：绘制MTF曲线
plt.plot(freq[:n//2], mtf)
plt.xlabel('Spatial Frequency (lp/mm)')
plt.ylabel('MTF')
plt.grid(True)
```
