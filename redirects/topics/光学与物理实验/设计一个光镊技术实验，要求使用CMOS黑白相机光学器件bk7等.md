以下是一个基于**光镊技术**的实验设计方案，使用**CMOS黑白相机**和**BK7光学元件**为核心器件，适用于操控微米级粒子（如聚苯乙烯微球或生物细胞）。实验聚焦于**单光束梯度力阱（Optical Tweezers）** 的搭建与验证，强调低成本和高可行性。

---

### **实验名称**  
基于CMOS相机与BK7物镜的单光束光镊系统搭建及微粒操控实验  

---

### **实验目标**  
1. 搭建简易光镊光路系统，使用BK7玻璃物镜聚焦激光形成光阱。  
2. 利用CMOS相机实时观测并记录微粒捕获过程。  
3. 定量测量光阱刚度（Trap Stiffness）。  

---

### **实验器材清单**  
| **类别**       | **具体器件**                                                                 |
|----------------|-----------------------------------------------------------------------------|
| **光源**       | 1064nm 连续波激光器（功率可调，0-2W，近红外波段减少生物损伤）                 |
| **光学元件**   | - BK7平凸透镜（焦距f=4mm，作为物镜）<br> - 扩束镜（5×扩束比）<br> - 二向色镜（反射1064nm/透射可见光）<br> - 反射镜（高反@1064nm）<br> - 样品池（载玻片+盖玻片腔体） |
| **成像系统**   | - CMOS黑白相机（如FLIR Blackfly S，帧率≥100fps）<br> - 白光LED光源（透射照明）<br> - 成像物镜（20×，NA=0.4，与光镊物镜共轴） |
| **样品**       | 聚苯乙烯微球（直径1.5μm，水溶液分散）                                        |
| **位移控制**   | 三维纳米位移台（精度±100nm，用于样品池移动）                                 |
| **信号处理**   | 示波器（监测激光功率波动）                                                  |
| **软件**       | Python/OpenCV（实时粒子追踪与位置分析）                                      |

### **实验光路设计（关键步骤）**  
```plaintext
 激光器 → 扩束镜 → 反射镜1 → 二向色镜 → BK7物镜（光阱聚焦）  
                      ↑  
 白光LED → 聚光镜 → 样品池 → 二向色镜 → 成像物镜 → CMOS相机
```
**说明**：  
- 激光路径：扩束后经二向色镜反射，由BK7物镜聚焦在样品池内形成光阱。  
- 成像路径：白光透射照明样品，反射光经二向色镜透射至CMOS相机，避免激光干扰成像。  

> 🔍 **为什么选择BK7物镜？**  
> - BK7是常见光学玻璃，成本低且透射率>90%（@1064nm），但数值孔径（NA）较低（本例中NA≈0.65）。  
> - 虽不如高NA物镜（如萤石）效率高，但足以捕获1–5μm微粒，适合教学级实验。

---

### **实验步骤**  
#### 1. **系统搭建与校准**  
   - 调节扩束镜：使激光束直径匹配BK7物镜后孔径（确保满孔径照明）。  
   - 共轴校准：使用可见红光指示光路，使激光焦点与CMOS成像中心重合（通过位移台移动样品微球验证）。  

#### 2. **光阱形成验证**  
   - 将聚苯乙烯微球溶液注入样品池，静置5分钟使微粒沉降。  
   - 开启激光（功率200mW），在CMOS图像中观察：  
     - 未捕获时：微粒随机布朗运动。  
     - 成功捕获：某一微粒被固定在激光焦点处，周围微粒运动不受影响。  

#### 3. **光阱刚度测量（功率依赖性）**  
   - **逃逸法**：逐渐增加位移台移动速度，记录微粒从光阱中逃逸的临界速度（`v_c`）。  
     - 光阱刚度 `κ = 6πηr v_c` （η：水黏度，r：微粒半径）  
   - **功率梯度**：测试激光功率（100–500mW）对刚度κ的影响，验证`κ ∝ P`。  

#### 4. **动态操控实验**  
   - 通过位移台移动样品池，使捕获微粒按预设轨迹（如圆形）运动。  
   - 使用OpenCV实时追踪微粒位置，生成运动轨迹图。  

---

### **数据采集与分析（Python示例）**  
```python
import cv2
import numpy as np

# 初始化CMOS相机
cap = cv2.VideoCapture(0)  # 连接相机
_, frame = cap.read()

# 粒子追踪（差分图像法）
while True:
    prev_frame = frame.copy()
    _, frame = cap.read()
    diff = cv2.absdiff(frame, prev_frame)
    gray = cv2.cvtColor(diff, cv2.COLOR_BGR2GRAY)
    _, thresh = cv2.threshold(gray, 25, 255, cv2.THRESH_BINARY)
    
    # 检测微粒中心
    contours, _ = cv2.findContours(thresh, cv2.RETR_EXTERNAL, cv2.CHAIN_APPROX_SIMPLE)
    for cnt in contours:
        if cv2.contourArea(cnt) > 10:  # 过滤噪声
            (x, y), radius = cv2.minEnclosingCircle(cnt)
            cv2.circle(frame, (int(x), int(y)), int(radius), (0, 255, 0), 2)
            print(f"Position: ({x}, {y})")
    
    cv2.imshow("Trapped Particle", frame)
    if cv2.waitKey(1) == 27:  # ESC退出
        break

cap.release()
cv2.destroyAllWindows()
```

### **注意事项**  
1. **激光安全**：1064nm激光不可见，需佩戴防护眼镜，避免直视或皮肤接触。  
2. **热效应控制**：BK7物镜吸收少量红外光会发热，连续工作需监控温度（建议加散热片）。  
3. **样品浓度**：微粒密度需适中（~0.1% w/v），避免多粒子干扰捕获。  
4. **像差校正**：BK7物镜在近红外波段存在色差，可通过光阑限制光束直径改善焦点质量。

### **预期结果**  
- 成功捕获1.5μm微粒时，CMOS图像显示微粒稳定停留在激光焦点中心（位置波动<50nm）。  
- 光阱刚度κ随功率线性增加（例：200mW时κ≈0.1 pN/nm）。  
- 位移台操控下，微粒可精准跟随圆形轨迹（误差<10%）。
