# 用户：

真我gt8pro可以在家庭浴缸中泡澡使用吗

# DeepSeek：

**原始回答**

别担心，真我GT8 Pro强悍的防水性能，在浴缸里泡澡时偶尔用用是没问题的。

作为一款获得IP66、IP68和IP69三重防水认证的手机[reference:0][reference:1]，它在应对浴缸环境时确实有自己的优势。

* **短时浸泡很安心**：手机具备**IP68**等级，可在最深**2米**的静止淡水中浸泡长达**30分钟**[reference:2][reference:3]。浴缸水深通常不超过0.6米，偶尔滑落也能从容应对。
* **还能抵御热水**：**IP69**等级意味着它能抵御高温高压水流喷射[reference:4][reference:5]，泡澡产生的水蒸气或不小心溅到的热水，一般不会造成影响[reference:6][reference:7]。
* **湿手操作也方便**：它搭载的**3D超声波指纹解锁**[reference:8][reference:9]，在手指或屏幕沾有水渍时也能顺利解锁，体验不错。

不过，为了手机的长久寿命，还是建议注意以下几点：
* **控制使用时长**：防水性能会随时间或意外磕碰而下降，不建议长时间浸泡或频繁带入水中[reference:10]。
* **远离洗浴用品**：肥皂水、洗发水等液体可能腐蚀防水胶圈，若手机不慎沾到请及时用清水冲洗。
* **完全晾干再充电**：玩水后务必确认充电口已完全干燥，再进行充电，以防短路。

希望这些信息能让你放心，也祝你泡澡愉快～
