# 用户：

天选5pro屏幕锁多少寸

# DeepSeek：

**原始回答**

华硕天选5 Pro的屏幕尺寸为**16英寸**，采用**16:10显示比例**，分辨率为**2560×1600（2.5K）**，并支持**165Hz刷新率**和**3ms响应时间**。这一设计优化了屏幕的屏占比，移除了前代产品的“大下巴”，提供了更大的垂直显示空间，适合游戏和多任务处理。

其他关键屏幕参数包括：
1. **色域覆盖**：100% sRGB色域，色彩表现精准，适合对色彩要求较高的创作或游戏场景。
2. **亮度**：400尼特，即使在明亮环境下也能清晰显示内容。
3. **技术特性**：支持G-Sync防撕裂技术和DC调光，减少画面卡顿并降低频闪对眼睛的负担。

此外，该屏幕为IPS面板，搭配窄边框设计，进一步提升了视觉沉浸感。
