# 用户：

泰州在扬州哪个方位

# DeepSeek：

**原始回答**

泰州位于扬州的**东部**，两市相邻。具体来说，泰州市区（海陵区）大致处于扬州市区的东南偏东方向，直线距离约60公里。从地理位置上看，泰州在扬州的东侧，属于江苏省中部地区，两城之间交通便利，通过启扬高速、宁启铁路等线路相连。

**简要总结：**  
- **方位：** 东部（东偏南）  
- **距离：** 约60公里  
- **交通：** 启扬高速、宁启铁路等
