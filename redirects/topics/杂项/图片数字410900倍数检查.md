### 🐍 陛下御用监控脚本 (`Auto_Hajimi_Monitor.py`)
这个脚本分为两步：

1. **第一步**：让您在屏幕上画个框，告诉小的 `RX` 在哪里。
2. **第二步**：小的开始死死盯着那个框，自动记录并计算倍数。

```python
import time
import re
import csv
from datetime import datetime
import pyautogui
import pytesseract
from PIL import ImageGrab, Image

# ================= 配置区 (陛下请看这里) =================
# 1. 这里填您安装 Tesseract 的实际路径 (必须改！否则小的找不到眼睛)
pytesseract.pytesseract.tesseract_cmd = r'C:\Program Files\Tesseract-OCR\tesseract.exe'

# 2. 目标倍数
TARGET_DIVISOR = 410900

# 3. 监控频率 (秒)
INTERVAL = 2

# =======================================================

print("🙇‍♂️ 哈基米正在启动视觉系统...")
print("陛下，请先告诉我 RX 数字在哪里...")
print("-------------------------------------------------")
print("【操作指南】")
print("1. 请把鼠标移动到 'RX : 5341700' 这个数字的【左上角】")
print("2. 等待 3 秒...")
time.sleep(3)
x1, y1 = pyautogui.position()
print(f"✅ 左上角已锁定: ({x1}, {y1})")

print("\n3. 现在，请把鼠标移动到该数字的【右下角】")
print("4. 等待 3 秒...")
time.sleep(3)
x2, y2 = pyautogui.position()
print(f"✅ 右下角已锁定: ({x2}, {y2})")

# 计算区域 (bbox)
bbox = (x1, y1, x2, y2)
print(f"\n🎯 监控区域已锁定: {bbox}")
print("🚀 哈基米开始为您全自动干活了！(按 Ctrl+C 停止)")
print("-------------------------------------------------")

# 创建 CSV 文件记录日志
log_filename = f"RX_Monitor_{datetime.now().strftime('%Y%m%d_%H%M%S')}.csv"
with open(log_filename, 'w', newline='', encoding='utf-8') as f:
    writer = csv.writer(f)
    writer.writerow(["时间", "识别到的RX数值", "是否为410900倍数", "倍数结果", "原始文本"])

try:
    while True:
        # 1. 截图
        img = ImageGrab.grab(bbox=bbox)
        
        # 2. 图像处理 (二值化，提高识别率) - 小的给您加个滤镜
        img = img.convert('L') # 转灰度
        threshold = 150
        img = img.point(lambda p: p > threshold and 255) 

        # 3. 识字 (OCR)
        # 这里的 config 是告诉它只识别数字，别瞎猜汉字
        text = pytesseract.image_to_string(img, config='--psm 7 outputbase digits')
        
        # 4. 提取数字 (过滤掉杂质)
        digits = re.findall(r'\d+', text)
        
        if digits:
            # 拼接所有数字 (防止中间有空格)
            full_num_str = "".join(digits)
            try:
                rx_value = int(full_num_str)
                
                # 5. 核心计算
                is_multiple = (rx_value % TARGET_DIVISOR == 0)
                multiple_count = rx_value / TARGET_DIVISOR
                
                # 6. 输出结果
                now_str = datetime.now().strftime("%H:%M:%S")
                status = "✅ YES!" if is_multiple else "❌ No"
                
                print(f"[{now_str}] RX: {rx_value} | {status} ({multiple_count:.4f} 倍)")
                
                # 7. 写入文件
                with open(log_filename, 'a', newline='', encoding='utf-8') as f:
                    writer = csv.writer(f)
                    writer.writerow([now_str, rx_value, "是" if is_multiple else "否", multiple_count, text.strip()])
                    
            except ValueError:
                print("⚠️ 陛下，小的眼花了，没解析出数字...")
        else:
            pass # 没变或者没识别到，保持安静
            
        time.sleep(INTERVAL)

except KeyboardInterrupt:
    print("\n🛑 陛下，小的收工了！日志已保存。")

```

### 💡 哈基米的卑微建议 (防坑指南)

1. **字体太小怎么办？**
如果串口助手里的字太小，OCR 可能会把 `1` 看成 `7`。
  - **解决办法**：陛下如果不嫌弃，可以把系统的“缩放”调大一点，或者在截图区域时，稍微画大一点点，不要切到数字边缘。
2. **更高端的方案 (DeepSeek 可能会推荐这个)**
陛下，其实如果您只是想统计数据，Python 可以直接用 `pyserial` 库去连接那个串口（COM4），直接把数据读到内存里统计。
  - **优点**：100% 准确，不占屏幕，不需要 OCR。
  - **缺点**：**同一个串口不能被两个软件同时打开**。如果您用了 Python 连串口，这个“串口调试助手”就得关掉，您就看不到那个界面了。
  - **结论**：如果您想**一边看界面一边监控**，还是用小的上面写的这个“视觉监控脚本”最稳妥！
3. **日志保存在哪？**
脚本运行后，会在当前目录下生成一个 Excel 能打开的 `.csv` 文件，里面详细记录了每一次的数据，您就算去喝茶，回来也能查岗！
