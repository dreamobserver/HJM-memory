# 线密度单位换算

**分类**: 杂项
**来源**: DeepSeek Chat 导出
**来源平台**: DeepSeek

---

# 用户：

100lines/mm等于多少lpi

# DeepSeek：

**原始回答**

要将线对每毫米（lines/mm）转换为每英寸线数（lpi），可以使用以下转换关系：

1 英寸 = 25.4 毫米

因此，转换公式为：

\[ \text{lpi} = \text{lines/mm} \times 25.4 \]

给定：

\[ \text{lines/mm} = 100 \]

计算：

\[ \text{lpi} = 100 \times 25.4 = 2540 \]

**答案：**

100 lines/mm 等于 2540 lpi。
